## 方式と実装の変種

| 方式 | 本画面の実装 | 平均 | 最悪 |
| --- | --- | --- | --- |
| クイック | 末尾ピボット。未満と以上に分割するLomuto方式 | O(n log n) | O(n²) |
| バブル | 左から隣接比較し、最大値を末尾に確定。早期終了なし | O(n²) | O(n²) |
| 選択 | 未確定部分の最小値を探索し、先頭と交換 | O(n²) | O(n²) |
| 挿入 | 一時保持・空き領域・右への1位置シフト | O(n²) | O(n²) |
| マージ | 位置で二分し、左優先の同値比較で補助領域へ併合、逐次書戻し | O(n log n) | O(n log n) |
| ヒープ | 下から最大ヒープを構築し、ルート取出し後に下向き修復 | O(n log n) | O(n log n) |
| シェル | floor(n/2)を整数で半減し、各間隔で挿入整列 | 間隔列に依存 | 間隔列に依存。本実装はO(n²) |

安定性は実装の性質として説明する。等しい値を交換しないバブル、追い越さない挿入、同値なら左優先のマージは安定。ここで採用したクイック・選択・ヒープ・シェルは安定ではない。シェルに別の間隔列の計算量を適用しない。

## 状態記録と描画

sort-engine.jsは描画に依存せず、実際の整列から全ステップを生成する。元の要素をidとvalueで区別し、重複値も移動を追える。各snapshotを深く凍結し、描画側は選択したsnapshotだけを読む。先頭への復帰・逆送り・シークの際にアルゴリズムを逆実行したり、乱数で状態を作り直したりしない。

各ステップは配列、操作種別、説明、比較した値と位置・判定、移動の出発点と到着点、確定位置、部分整列の範囲とstride、処理範囲、フェーズ、累積回数、方式固有の状態を記録する。比較と条件判定は別ステップだが比較回数は1回。自己交換は0回。交換1回、シフト1要素、保持値の挿入、併合先書込み、配列書戻し、一時保持を別々に集計し、合算した曖昧な移動回数を表示しない。

クイックはpivotの値・id・現在位置、再帰深さ、調査済み左右群を保持する。挿入とシェルは保持値とnullの空き領域を持ち、保持値を含めると元の全要素が揃う。シェルはgapと同じ剰余のグループを表示する。整列済みグループは、最終位置の確定と区別する。

マージは左右の整列済みグループ・各先頭cursor・補助output・分割／併合／書戻しの状態を保持する。元の配列を書き戻す途中は同じ要素のコピーが並ぶ場合があり、補助領域を併記して説明する。各書込みを記録し、描画のために架空の交換を挿入しない。

ヒープは有効要素数・調査する親子・構築／修復／成立の状態を持つ。木の位置iから2i+1・2i+2へ接続し、棒と同じsnapshotの値を表示する。取出し交換の直後も「修復中」とし、壊れたヒープを成立と表示しない。

## 入力と操作

「動作を見る」「選択肢を確認」「7方式を比較」のセグメントコントロールで、対応する1パネルを表示する。比較のパネルには計算量の数値例も含む。矢印キー・Home・Endで表示とフォーカスを切り替え、選択中のタブだけをTab停止点にする。動作パネルを離れると再生を一時停止し、数列・方式・ステップは保持する。他のパネルで再生用のショートカットを実行しない。選択肢カードから方式を選ぶと動作パネルへ戻り、再生を初期化してドロップダウンへフォーカスする。

7方式の選択はドロップダウンとし、PCでは入力数列・適用・初期数列の操作と同じ行に並べる。狭い画面では選択欄と入力欄を縦に並べる。状態色と通常UIは共通CSSの変数を使う。

図・入力・再生・説明を一つの枠へまとめ、図を横幅全体へ配置する。図の横の状態カード、独立した再生カードと学習ポイントカードは設けない。図の表示領域は340pxとする。760px以下の図見出しは最小128pxとし、320px幅でも処理範囲と木構造切替を折り返して表示する。再生操作の後に置く説明領域はPCで最小240px、760px以下で最小320pxとし、内容や文字サイズに合わせて自然に伸ばす。本文・説明欄の縦スクロールは設けず、共通ホストが内容高へ追従して出典・参考資料・フッターまで画面全体でスクロールする。一時保持・グループ・併合補助領域は図内の80pxの補助領域に表示する。ヒープの木構造は「木構造を見る」で配列と同じ図の領域へ切り替え、方式・入力・ステップを保持する。入力エラーも案内と同じ予約行を使う。選択・補足の開閉・方式切替・全ステップの再生で操作ボタンの位置を変えない。

開始前には方式の概要と操作案内、再生中には現在のステップと関連する状態、完了時には方式を見分けるポイントを表示する。要素を選ぶと再生を止め、ステップ説明をその要素の説明へ切り替える。同じ要素の再選択、閉じる又はEscapeで解除し、閉じると元の棒へフォーカスを戻す。再生・手動送り・シークでは要素の選択を解除してステップ説明へ戻す。「方式の補足」「操作回数を確認」「図の見方・キー操作」は要求された一つだけを展開する。回数は閉じている間も同じsnapshotへ更新し、方式・数列を変更すると補足を閉じる。アプリ内では親画面と重複するタイトル・導入・ライセンス案内を隠し、親の出典・参考資料欄を使う。直接表示ではそれらを保持する。

初期数列は8,3,5,1,7,2,6,4。4〜10個、0〜99の整数をカンマ／全角カンマ／読点で区切る。空の値、個数、小数・文字、範囲外は具体的な日本語エラーを表示し、直前の正常な数列を維持する。重複値・同値・整列済み・逆順を受理する。適用した数列は方式を変えても共通で、方式・入力の変更時は再生を先頭へ戻す。初期数列へ戻すボタンも設ける。

最初・前・次・再生／一時停止・シーク・ゆっくり1600ms／ふつう850ms／速い350msを提供する。手動移動は再生を停止する。速度変更は現在位置から次の待ち時間へ反映する。最終snapshotで停止し、非表示になった場合も再生を止める。左右キー・Home・End・Spaceのショートカットを設け、入力欄・ボタン等の標準キー操作を妨げない。

棒を選択すると値・入力時の位置・現在位置・全状態ラベルを表示する。色に加え文字を併記する。位置は0始まり。隣接snapshot間の要素idの移動をアニメーションし、書戻し中のコピーを架空の交換にしない。reduced motionでは静止状態の切替にする。本体のsrc/ui/tokens.cssをtheme.cssへ複製してライト／ダークの背景・パネル・文字・ボタンを同じ無彩色に揃える。ホスト内では本体が渡す最新の正本CSSを適用する。比較・移動・ピボット・部分整列・位置確定の説明用の色も、正本の--visual-*を参照する。入力エラーは共通の--text-dangerを使う。44px以上の操作対象、可視フォーカス、狭い画面、グラフと表内だけの横スクロールを用意し、[共通色](/screens#共通色の定義と利用)と[共通スクロール表示](/screens#共通のスクロール表示)を継承する。
