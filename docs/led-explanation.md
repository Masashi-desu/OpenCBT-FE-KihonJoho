# 7セグメントLEDの点灯判定

2016年度秋期 基本情報技術者試験 旧制度・午前 問21（原資料p.13）の詳細解説。D/A変換解説のビットと図の対応、2進数変換解説の前後移動を参考にし、共通の詳細解説ホストで表示する。

## 学習の焦点と操作

主図の上段では2進数をP7から読み、回路図では原図と同じくP0を一番上に置く。回路図の各行でポートから抵抗をたどると、同じ高さのLED端子に行き着く。VccはLEDの共通アノードに接続する。初期状態では配線の読み方と「0で点灯、1で消灯」を示す。次へ進むと16進数を上位・下位4ビットずつ展開し、P7→DtからP0→aまで一端子ずつ判定する。最後は点灯した位置と全4選択肢を比較する。原問は92₁₆＝1001 0010₂。a・c・d・f・gが点灯し、ウの図に一致する。数値の並びをそのまま点灯の並びと解釈しないこと、小数点DtもP7の出力で判定することが学習の焦点。

「戻る」「次へ」、位置スライダーで往復できる。配線の行・LEDの図形やラベルから、その端子の判定へ直接移動できる。変換時は対応する4本の配線とビットの組を示す。点灯判定時は1本の配線・対応ビット・LEDの位置を同時に強調する。出力が0のときはVccと配線上の左向き矢印で電流の向きを示す。出力が1のときは点線の配線と消灯で示す。LEDの未判定は破線、消灯は輪郭のみ、点灯は塗りつぶしで区別する。完了後に選択肢を押すと異なる箇所を文章と図の破線枠で示す。同じ選択肢の再選択かEscapeで比較を解除し、操作元へ戻る。編集結果がどの選択肢とも一致しない場合も表示する。図とステップ操作は状態が変わっても同じ位置に置き、説明・入力エラー・比較は図の後で自然に伸びる。狭い画面では配線とLEDの表示を上下に並べる。配線のP0〜P7の順番と、右側の対応端子は画面幅によらず共通とする。共通色・フォーカス・単一縦スクロールを使い、埋め込みでは出典を親に任せる。

Vccのラベルは通常時に0.85em、回路の読み取りと電流が流れる段階で1emとする。強調時の行の高さ1.25emと幅2.5emを常に確保し、文字の大きさが切り替わっても電源の接続線、配線、LEDの表示位置を保つ。

## 入力と保存

図中の16進数は00〜FFの2桁を直接編集できる。小文字・全角の16進数字も受け付け、有効な値を入力すると同じ段階で再計算する。未入力・1桁・範囲外は入力欄だけに保持し、直前の有効な出力での表示であることを示す。同値入力やIME変換途中は結果を更新しない。値が変わると選択肢の比較を解除し、「問題の初期値に戻す」は保存された値と最初の段階へ戻す。生成問題は生成器3.2.0の保存済みケース番号と各選択肢の図の状態・表示順を受け取り、再抽選しない。解説の編集は保存済みの問題・回答・採点から独立している。
