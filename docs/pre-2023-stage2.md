## 旧午後の選択と保存

「旧制度・午後」として、科目Bの現行問題集と区別する。学習・復習では収録13大問すべてを扱い、時間付き練習では公式の必須・選択区分を満たす7大問を開始前に選ぶ。2017年春期の公式表紙では問1・問8が必須、問2〜7から4大問、問9〜13から1大問、制限時間は150分である。以後の各冊子も表紙と解答資料を個別に確認する。

完全な原問題集の `set.questionSelection` に、必須参照、選択区分、各区分の選択数、根拠資料、公式の超過時の冊子順規則を保持する。アプリでは選択超過を許さず、規定数が揃うまで開始を止める。`selection.selectedQuestionRefs` は当該冊子の原問題の改訂を固定した参照とする。選択した順にかかわらず冊子順で出題し、非選択大問を採点分母へ含めない。解答欄数は選んだ大問によって変わり、公式得点・IRT評価点は算出しない。

ランダムミックスも選んだ大問ごとに対応する生成器を一度ずつ使う。分野の件数だけを合わせて言語問題を別の大問へ置き換えない。旧午後を現行科目Bの全体ミックスへ流入させない。保存した原問題集の全参照・規則をsnapshotへ保持し、出題した参照、合法な選択、順序、制限時間を再開時にも照合する。

原資料の解答群を本文側へ保持する生成形式では、解答欄は本文の記号から選択し、同じ解答群を重複表示しない。解答群を解答欄へ分ける形式では必要な表・コード・文章をそこで表示する。いずれも原資料の記号順と複数解答欄・共有解答群を維持する。

## S2-01の資料範囲

原PDFの全88頁と公式解答78欄を照合した。共通疑似言語、必要なCASL/COMET資料、表計算資料を各大問の素材条件と対応づける。問12の付属資料p74下部にあるJIS X 0201文字コード表は利用条件未確認のため保留し、画像・抽出本文・ネイティブデータ・JavaScript・検索へ同梱しない。

問12の原問題は数値・アドレスの演算であり、この文字コード表を用いない。必要な資料はp72〜73、p74上部の命令と全注記、p75〜77である。p74上部は1432×2026pxの原画像から `[0,0,1432,1240]` を切り出す。表の最初の画素より16px上で切り、PUSH/POP/CALL/RET等とその注記を保持する。PDFの元DCT streamから得たPNGのSHA-256は `d57ee1019fda6c5e9752f681e0a2dcaa0c4f856c299f73a4aa1b02c22b2916e0`。初期監査の再JPEG化された画像とcropは配布へ流用しない。原本への出典リンクを保持し、生成条件も文字コード表に依存しない数値領域に制限する。これは未確認素材の許可判断を変更するものではなく、解答に不要な当該素材を配布から除く資料範囲の判断である。

権利・方式の独立監査packetは `output/source-review/stage2-s2-01-rights-rules-20261026-v1`、156項目のmanifest SHA-256は `40c5cbdd9fc5d64d9aded98a1277c0aabba7b63a4c141bbcde6f137d474fadc1`。原資料を含むこの開発証跡は配布対象へ加えない。

問12のa/b共通解答群は5択（ア〜オ）である。原監査packet内の6択という記録は、再照合した独立補遺 `stage2-s2-01-rights-rules-correction-20261026-v1` で訂正した。補遺manifestのSHA-256は `a2f83fdd0c991da6100e313286fbd6696fe8dbb10a8eb45a182d3f858f9faf12`。元の封印は保持し、実装・検証では訂正後の5択を用いる。6解答欄と公式正答はこの訂正の影響を受けない。

画像抽出方法と画素一致の主張は続くv2補遺で訂正した。v2のmanifest SHA-256は `43557fe1a335a05bda3c7464951f33372ffc8b5c2c357832b76ca0877772a0cd`。全88頁の目視と資料範囲の判断を保持し、配布画像は元streamから改めて抽出して検査する。

## 問題集ごとの配布判定

13大問それぞれについて原問題・基準問題・生成器・ミックス枠・必要素材・説明・出典・用途別権利情報・独立内容検査・表示査読を揃える。年度別、選択7大問の時間付き練習、ミックス、検索、ブックマーク、回答・採点、保存・再開・履歴を実データで検証する。現行問題・2022年サンプルの回帰検査、素材と配布グラフの確認、必須の `npm run check` に成功してから合流候補を作る。

最新mainを基に完成した1問題集と必要な共通修正だけを候補へ取り込み、未確認素材や未完成の別年度を公開Git履歴・実行コード・配布データへ含めない。候補でも検証し、並行作業を保持してmainへ合流・pushする。CIと実際の配信を確認後、mainの内容をfeatへ戻して次の問題集へ進む。

## S2-01の資料単位

2017年度春期・旧午後の13大問には、原問題13件・基準問題13件・生成器13種類と83点の原資料画像を対応付ける。問13は本文9頁、表計算付属資料p78〜83の6頁、マクロの構文を読むための共通疑似言語資料p3〜4の2頁を使い、原問題側に17点、生成版の固定参照資料に8点を保持する。付属資料の出典・権利は本文と分けて維持する。生成版の問題本文・式・ワークシート・マクロ・解答群は管理コードで描き、固定の原問題画像を流用しない。
