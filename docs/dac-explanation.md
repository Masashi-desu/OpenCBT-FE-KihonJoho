# D/A変換・1ビット分の電圧を求める

2017年度 春期 基本情報技術者試験 午前 問20の詳細解説をpublic/explanations/ipa-2017-spring-am-20/に配置する。通常解説・復習・検索から共通の隔離ホストで開く。キャッシュヒット率解説の段階計算と全選択肢の代入比較、2進数変換解説のビットと数値の対応を参考にする。追加ライブラリは使わない。

## 学習の焦点と表示

冒頭文の直下に、分解能・試す入力と、二つの出力を比較する図をまとめる。比較する各行の枠内に、その行の十進入力コード、全ビットと各桁の重み、対応する出力電圧を置く。ビットを押すとその行の入力コードを起点に反転し、重みを押すと同じ行での寄与を説明する。分解能と試す入力は二つの行に反映する。「最下位ビットを反転」は「現在」の入力に作用する。「現在」の行を上に置き、最下位ビットが変わって順序が入れ替わるときは移動をアニメーションで示す。動きの軽減設定時は順序を即時更新する。V₁とV₀の添字は最下位ビットの値を表し、差は行の上下によらずV₁−V₀で求める。広い画面では括弧で二つの出力を結ぶ。狭い画面では各行のビット列の直下に出力を置き、両方のV₁・V₀を差のラベルでも照合できるようにする。ステップ4から式と同じ数値を表示し、それまでは未計算の出力を「？ V」で示す。記号と数値の長い方に必要な高さを確保し、段階の移動で図や操作がずれないようにする。

入力128で2.5Vという対応から1 LSBを求める。8ビットのコードの通り数256、最大コード255、与えられた入力128を区別する。6段階（既知の対応／コード範囲／LSBの重み／電圧差を段階数で割る／代入検算／全選択肢比較）を戻る・次へ・スライダー・段階選択で往復できる。1 LSBは2.5/128V、公式正解ア。全4択の2.5/128・2.5/255・2.5/256・2.5/512を現在の入力へ代入し、一致と分母の役割を示す。有限小数8桁で正確に表せない数は既約分数にし、近似値へ等号を付けない。

主図を囲むカード内の最上部に、既知の対応と求める電圧変化を一文で中央寄せにする。原問題では「ディジタル値0を入力したときの出力電圧が0Vとなり、ディジタル値128を入力したときの出力電圧が2.5Vとなる場合、最下位の1ビットの変化による当該D/A 変換器の出力電圧の変化は何Vかを求める」と表示する。入力欄で確定した基準入力・電圧は、冒頭の文章、図のA・B、式、1 LSBの計算で共有する。生成問題では保存された条件から初期表示する。試す入力を変えると、同じ変換器で求めた出力を冒頭文・基準入力と電圧・図のAとB・途中式・選択肢の検算に反映する。無効入力中は直前の有効な計算を表示する。数値の編集で図が動かないよう、実幅・文字サイズと入力域内の最長値で必要な段落高さを測る。

主図は、ビット操作と出力の比較、既知の二点の対応、差と分数を一つの全幅領域へまとめる。十分な幅では基準点と途中式を左右に隣接させ、その間隔を16px、狭幅で上下に並ぶ場合を12pxとする。A・Bから求めた1 LSBを上の比較図のD/A変換に使う。基準点には「入力0と現在の入力での対応」を示し、基準入力と基準の出力電圧の二列とし、0→0Vと基準入力→基準電圧を同じ行に揃える。二点間の増加量に「B：入力差」「A：電圧差」を置き、式でも同じ記号を付ける。第4段階の分数はAを分子、Bを分母にし、出所の図に続けて読む構造とする。基数変換解説の、対応する値を揃えて計算を間に置く判断も参照する。

式のA・Bを選ぶと、図の差・元の入力欄と該当する項だけを枠で強調し、主要操作の後の説明をその値の出所へ切り替える。図の差を選ぶと式の対応項を選択表示する。分解能Dはコードの通り数・最大コードと関係付け、分母Bとの違いを説明する。Cは重み1の最下位ビットへ対応付ける。記号・枠・選択中の下線・押下状態を併用し、色だけで対応を示さない。同じ対象の再選択・選択解除・Escapeで解除する。解除時は選択元へフォーカスを戻す。入力欄へのフォーカスでもその出所を示し、入力値を編集すると図・式・説明を同じ有効な計算状態から更新する。

操作するコードは「試す入力」の十進入力とビット列で表し、同じ状態を双方向で更新する。上の試す入力と下の基準入力は同じコードを編集する。ビットまたはコードを変えると、現在の1 LSBからその入力の出力を正確に算出する。下の電圧を編集すると、その入力での新しい出力を指定して1 LSBを調整する。各ビットの0/1で試す入力を変更し、重みボタンでその桁の寄与を表示する。選んだ桁の説明はA÷Bで得た1 LSBに重みを掛ける式を含み、他の補足と排他的に表示する。入力128と129、127と128などを比較でき、繰上がりのあるコード差1と最下位ビットだけの反転を用語補足で区別する。入力0・最大コード・基準コードと異なる任意の入力も扱う。第3段階とCの選択時には図内の横スクロールを最下位ビットが見える位置へ合わせる。

基準入力・電圧は対応の表示そのものから直接編集し、分解能の選択欄Dは図内のビット列直前に置く。通り数・最大コードも同じ行に添え、選択するとビット数・範囲・Dの途中式へ反映する。試す入力の出力は比較図の「現在」の行で読む。現在の説明と選択対象の説明は主要操作の後の一か所を切り替え、選択肢比較は最終段階だけ表示する。段階の移動で選択を解除して、その段階の焦点へ戻す。条件編集では段階と選択を保持する。詳しい前提・用語・操作は開閉する補足へまとめ、親のタイトル・出典は重複させず、単独表示だけ見出しと出典を出す。

ビット列は44px以上の操作対象を維持して領域内だけ横スクロールする。図の配置は全段階で保持し、値の出所を指す矢印は基準点の左右／上下配置へ合わせる。式は実際の幅と文字サイズで全6段階と、0・1・基準・最大・最大−1・現在のコードの必要高を測り、その最大値だけを予約する。一時的な非操作・inertの計測要素は直後に削除する。幅・文字サイズ・条件の変更時に再測定し、説明・補足は自然に下へ伸びる。本文は共通ホストの単一縦スクロール、共通tokens.cssと前面スクロールバーを使用する。

## 入力・保存・出典

解説用の分解能は2〜12ビット、入力コードは0〜最大コードとする。入力が1以上なら、その入力での電圧を0より大きく100 V以下、小数第3位まで指定できる。計算で得た出力は既約分数または有限小数でそのまま表示する。入力0では電圧を0 Vに固定し、入力0と1の出力差から1 LSBを表示する。全候補を入力0に代入すると出力は0 Vなので、判定は各候補の1 LSBを直接比較する。理想的な比例モデルと入力0で0Vを明示し、実機の誤差や非線形性は範囲外にする。有効な入力を随時反映して計算段階と選択を保持し、同値入力は再描画しない。変換途中・無効な入力は直前の有効な図と計算を保ち、エラーに修正範囲と復旧方法を表示する。ビット操作は無効入力中に実行しない。分解能を小さくして入力コードが範囲外になった場合も、値を黙って置換せず修正を求める。初期化で保存条件・最初の段階へ戻す。
