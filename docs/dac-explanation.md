# D/A変換・1ビット分の電圧を求める

2017年度 春期 基本情報技術者試験 午前 問20の詳細解説をpublic/explanations/ipa-2017-spring-am-20/に配置する。通常解説・復習・検索から共通の隔離ホストで開く。キャッシュヒット率解説の段階計算と全選択肢の代入比較、2進数変換解説のビットと数値の対応を参考にする。追加ライブラリは使わない。

## 学習の焦点と表示

入力128で2.5Vという対応から1 LSBを求める。8ビットのコードの通り数256、最大コード255、与えられた入力128を区別する。6段階（既知の対応／コード範囲／LSBの重み／電圧差を段階数で割る／代入検算／全選択肢比較）を戻る・次へ・スライダー・段階選択で往復できる。1 LSBは2.5/128V、公式正解ア。全4択の2.5/128・2.5/255・2.5/256・2.5/512を元の入力へ代入し、一致と分母の役割を示す。有限小数8桁で正確に表せない数は既約分数にし、近似値へ等号を付けない。

主図は、既知の二点の対応、差、分数、ビット列、試す入力と出力を一つの全幅領域へまとめる。十分な幅では基準点と途中式を左右に隣接させ、その間隔を16px、狭幅で上下に並ぶ場合を12pxとする。説明カードとして分割せず、同じA・Bから求めた1 LSBを直後の変換器へ使う。基準点は「1 LSBを求める既知の対応」と明記し、基準入力と基準の出力電圧の二列とし、0→0Vと基準入力→基準電圧を同じ行に揃える。二点間の増加量に「B：入力差」「A：電圧差」を置き、直下の式でも同じ記号を付ける。第4段階の分数はAを分子、Bを分母にし、値を横の説明カードへ移さず、出所の図に続けて読む構造とする。基数変換解説の、対応する値を揃えて計算を間に置く判断も参照する。

式のA・Bを選ぶと、図の差・元の入力欄と該当する項だけを枠で強調し、主要操作の後の説明をその値の出所へ切り替える。図の差を選ぶと式の対応項を選択表示する。分解能Dはコードの通り数・最大コードと関係付け、分母Bとの違いを説明する。Cは重み1の最下位ビットへ対応付ける。記号・枠・選択中の下線・押下状態を併用し、色だけで対応を示さない。同じ対象の再選択・選択解除・Escapeで解除する。解除時は選択元へフォーカスを戻す。入力欄へのフォーカスでもその出所を示し、入力値を編集すると図・式・説明を同じ有効な計算状態から更新する。

操作するコードは「入力コード（試す入力）」の一つの十進入力とビット列で表し、同じ状態を双方向で更新する。基準入力を有効な値へ編集したときは、試すコードとビット列をその基準入力へ揃えて、まず既知の点の一致を確認できるようにする。そこから試すコードを変更しても基準点は保持し、1 LSBが一定の変換器で出力が変わることを確認する。基準点と試すコードの両方を無条件に同時変更して、出力が常に基準電圧になる構成にはしない。各ビットの0/1で試す入力を変更し、重みボタンでその桁の寄与を表示する。選んだ桁の説明はA÷Bで得た1 LSBに重みを掛ける式を含み、他の補足と排他的に表示する。入力128と129、127と128などを比較でき、繰上がりのあるコード差1と最下位ビットだけの反転を用語補足で区別する。入力0・最大コード・基準コードと異なる任意の入力も扱う。第3段階とCの選択時には図内の横スクロールを最下位ビットが見える位置へ合わせる。第1〜3段階の出力は既知の2点以外を「ステップ4で計算」とし、第4段階以降に試す入力の出力を示す。

基準入力・電圧は対応の表示そのものから直接編集し、分解能の選択欄Dは図内のビット列直前に置く。通り数・最大コードも同じ行に添え、選択するとビット数・範囲・Dの途中式へ反映する。重複する適用フォームや自動再生は設けない。式を独立したカードにせず、主図内で二点の対応に隣接させ、ビット列・変換器をその直後へ置く。現在の説明と選択対象の説明は主要操作の後の一か所を切り替え、選択肢比較は最終段階だけ表示する。段階の移動で選択を解除して、その段階の焦点へ戻す。条件編集では段階と選択を保持する。詳しい前提・用語・操作は開閉する補足へまとめ、親のタイトル・出典は重複させず、単独表示だけ見出しと出典を出す。

ビット列は44px以上の操作対象を維持して領域内だけ横スクロールする。図の配置は全段階で保持し、600px以下では入力から右の変換器、さらにその下の出力へ矢印で接続する。値の出所を指す矢印も、基準点の左右／上下配置へ合わせる。式は実際の幅と文字サイズで全6段階と、0・1・基準・最大・最大−1・現在のコードの必要高を測り、その最大値だけを予約する。出力も同じコードと計算前の案内を測り、1ビットの変更で小数が折り返しても図や操作が動かないようにする。固定の大きい最小高を設けず、図と式の関係を余白で切り離さない。一時的な非操作・inertの計測要素は直後に削除し、非表示の解説パネルを残さない。幅・文字サイズ・条件の変更時に再測定し、説明・補足は自然に下へ伸びる。内部の縦スクロールや固定フッターを設けず、共通tokens.cssと前面スクロールバーを使用する。
