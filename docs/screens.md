# 画面・操作・状態遷移

## 画面構成と遷移

本システムでは独自UIを採用する。デスクトップのS03／S07は左に問題資料、右に解答・解説を分け、狭い幅では縦並びにする。全画面に非公式表示と画面名を置く。画面の配置・見直し・解除・結果表示は本アプリの要件であり、FE本番の全操作を確認できたと表現しない。[資料と要件の対応](/ui-reference)を参照する。

```text
S01 セット・科目・モード選択
  ├─ ブックマーク ─ 類題のS03 ─ 次の類題のS03
  ├─ S11 ライセンス一覧 ─ S01
  ├─ S08 学習記録・保存設定 ─ S06 結果 ─ S07 復習
  └─ S02 開始前説明／再開選択
        └─ S03 問題表示
              ├─ S04 問題一覧 ─ 選んだ問題のS03
              ├─ S05 終了確認 ─ S06 結果 ─ S07 復習
              ├─ S09 出典・改変詳細 ─ 元の画面
              └─ study中断 ─ S01（paused）
全画面のデータ／保存エラー → S10 エラー
```

S04・S05・S09はダイアログとして表示し、戻ると起点にフォーカスを返す。S06・S07・S08・S11はページとして遷移し、主見出しへフォーカスする。再開可能なセッションがある場合、新規開始と再開を別ボタンにする。

## 共通の表示モード

サイドバーのブランドアイコンは、独自の開いたフレームとFEを組み合わせた正方形ベクタを使う。CSSマスクでライト／ダークの文字色に追従し、OpenCBTと「基本情報技術者試験」を併記する。ファビコンも同じベクタから作る。[生成方法](/brand-icons)を参照する。サイドバーの英語見出し、表示モード名・現在のモードの文字、重複する上部ヘッダーは置かず、ナビゲーションと太陽・月の操作を表示する。

サイドバー下部に、Lucideの太陽・月アイコンによるライト／ダークモードの切替を置く。選択中のボタンはaria-pressedと背景・境界で示し、アイコンだけに意味を依存させず「ライトモード」「ダークモード」のアクセシブル名を持つ。Tabで移動し、Enter又はSpaceで切り替える。800px以下の横並びではロゴとナビゲーションを1段にまとめ、切替をページのフッタへ移す。ナビゲーションは中央にアイコンを表示し、操作名を読み上げ用に保持する。以前のサイドバー下部の注意書きブロックは設けない。

初期値はライトとし、選んだ値を同一originのlocalStorageのopencbt-fe-kihonjoho-themeへ保存する。再読み込みでは本体画面を描画する前に復元する。保存できない環境でも現在の画面の切替は使える。別タブの設定変更も反映する。学習記録の削除と表示設定は別に扱い、表示設定はブラウザのサイトデータ消去又は再選択で変更する。

表示モードはメニュー、開始前説明、問題、結果、復習、履歴、ライセンス、ダイアログへ共通に適用する。両モードとも白・黒・グレーを基本とし、背景・文字・ボタン・選択状態・問題番号・管理された図表を無彩色で統一する。正答・正誤、注意・見直し・改変、エラーなど意味を伝える表示には専用の状態色を使い、文字・アイコンも併用する。問題の生成値・選択肢順・解答・時計を変更しない。原資料画像を反転・加工せず、管理された図の背景・線・文字、表、疑似言語、数式と各状態の色を調整する。原資料と権利情報の表示条件は両モードで維持する。

## S01 — セット・科目・モード選択

- 目的：学習対象を明示して選ぶ。
- 表示：非公式表示、A／B、年度別オリジナルとランダムミックス、mode・時間・出題数、保存済みセッション、S08へのリンク。開始とは別の「ライセンス表記」ボタンを置く。元データ使用／生成の経路はセットに連動し、別の選択欄にはしない。全件の生成対応は開発規約と検証で維持する完了条件とし、対応テンプレート数・バインド方式・同系列の異なる入力を含むという説明欄は設けない。変更前の固定ミックスは旧記録と表示し、生成方式へ変更して再開しない。
- 操作：学習モードを「学習・復習」「時間付き練習」「無限周回」から先に選び、科目を選ぶ。通常の2モードでは年度別オリジナル／ランダムミックスと、年度又は分野構成の基準年度・問数を表示する。「開始前の説明へ」→S02。年度別は元データ使用、ミックスは全問の値生成・バインドに固定し、独自セット・補充チェック・出題方式の別選択は設けない。無限周回では出題セット・年度・問数を非表示にし、選んだ科目の収録生成系列から毎回ランダムに問題定義を選び、類題を生成する。通常モードへ戻ると前の設定を復元する。ここではタイマーを開始しない。保存中セッションの「再開」で当時の問題を使用する。「ライセンス表記」→S11はセット選択や数式準備の完了を必要としない。
- 状態：データ読込み中は開始不可。未選択は必要項目をテキストで示す。practice不足はボタンを無効にして不足数・分野を示す。選択変更時はモードの可否を再評価する。
- 例外：catalog検証失敗・参照切れはS10。無効なセットを有効な別セットへ自動置換しない。CDN障害でメニュー全体やライセンス操作を無効にしない。

```text
OpenCBT-FE-KihonJoho　非公式のFE学習・操作練習
科目・セット・モードの選択
[テスト開始／学習開始] [学習記録] [ライセンス]
数式の表示には外部CDNへの通信を使用します。
```

## S02 — 開始前説明・再開選択

- 目的：時間、保存、出典、支援機能、本番との差を理解して開始する。
- 表示：選択した科目・セット・mode・bindingMode・問数・制限時間、操作説明、practiceは通常中断でも期限継続、studyの正答表示と一時停止、保存180日、公式成績を算出しない旨。新規開始で過去の解答を使い回さないことを示す。latexがある場合はKaTeX・CSS・フォントのCDN取得と準備状態を示す。
- 操作：「開始」→readyの検証・保存後runningのS03。「選び直す」→S01。再開時は「保存した状態から再開」又は「記録を破棄して選び直す」。記録の削除は履歴画面で確認して行う。UIにabandonedを作る操作は初期版では設けない。
- 状態：新規説明中はタイマー未開始。生成可能な枠では「元データを準備中」と表示して元questionと依存素材を保存する。値の生成を選択したときだけ「値を生成してバインド中」と表示し、パラメータ選択・全内容検証・instance保存まで開始操作を無効にする。元データ使用では生成器を呼ばない。数式がある場合も[数式の準備](/content-format)が終わるまで無効にする。CDN障害では開始せず再試行・S01・S11への操作を維持する。S11から戻ると選択内容を保ったS01へ戻る。再開時は保存内容を読み、再生成しない。再開説明中もpracticeの期限は進む。期限超過ならexpiredのS06へ。
- 例外：権利・出典・正答・アセット・必要数・hashの検証失敗又は保存不可は開始せずS10へ。適法性確認をSchema成功で代替しない。

## S03 — 問題表示

- 目的：問題を読み、解答・移動・見直しを行う。
- 表示：科目・mode、practiceの残り時間、studyの稼働時間、[出典・権利・改変フッター](/attribution)、共通本文、設問、選択肢、独自解説の表示操作（studyのみ）、前後・一覧・終了・中断（studyのみ）。全幅の状態バーは置かず、解答領域の設問欄に現在位置「問題n／全N問」、未解答／解答済み／見直しの文字と記号、保存状況をまとめる。設問欄の下には矩形の選択肢を並べる。フッターに公開情報をもとにCBTの画面・操作を再現した旨を示す。
- 操作：選択肢の行を押してselectedChoiceIdを設定する。丸いラジオボタンと右端のチェックは表示せず、その幅を選択肢の本文・図表へ使う。選択状態は太い枠と背景、読み上げでは選択済みの状態で示す。キーボード操作と単一選択のための入力要素は画面に表示しない。別選択肢で変更し、選択済みの行をもう一度押すとフィールドを省略して未解答へ戻す。解除専用ボタンは置かない。正答は選択肢の枠・背景と解説欄の「正答：」で示す。解答フッターで「前へ」の左に旗アイコンを置き、reviewFlagを独立に切り替える。旗には操作名と押下状態を読み上げ用に付ける。一時停止・正答表示・問題一覧はヘッダーの「学習・操作補助」領域へまとめ、資料一覧・ドラッグスクロール・ズームは独立した「問題資料の表示操作」領域に置く。全操作は保存完了を通知する。
- 遷移：「前へ／次へ」→同じS03の別問。「問題一覧」→S04。「終了」→S05。「出典・改変の詳細」→S09。「中断」→paused保存後S01。
- 状態：先頭の前へと、問数を指定した練習・復習の末尾の次へは無効。無限周回の末尾では「次へ」で新しい問題を同じ練習へ追加し、前へ戻った場合は保存済みの次問へ移動する。未解答でも移動できる。studyの「正答・解説を確認」は表示後revealedを維持し、独自解説を明示する。practiceで正答・解説を出題中に表示しない。
- 例外：期限を各操作の前に評価し、到達なら入力を拒否してexpiredのS06。不正データ・画像欠落・参照切れは現在の操作を止めinvalidatedのS10。正答情報が欠けた問題を推測で出さない。保存失敗も操作を止め、最後の保存状態を示す。

解答・復習のヘッダー上段は本アプリのロゴ、科目・モード、練習名、ブックマーク、一時停止・再開、正答表示、問題一覧をまとめる。資料一覧のレフトカラムアイコン、手ボタン、＋、−、ズームのドロップダウンは問題資料の上に同じ高さ・上下位置で並べ、時間表示・終了操作は解答領域の上に置く。復習では終了が結果へ戻る操作になる。各領域の操作を対応する内容と一体に配置し、デスクトップでは境界位置と左右の高さを揃える。指示された操作だけを追加・置換し、補足見出しは置かない。狭い画面の縦並びでは、上段、資料の表示操作、問題資料、時間表示・終了操作、解答領域の順に表示する。どのヘッダーも上部に固定せず、ページのスクロールで上へ流れる。

静的ワイヤーフレームは情報の順序を示す。デスクトップでは共通本文・原文・図表を左の問題資料として保持する。「問題資料」「原文・図表」「生成した問題・図表」の見出しバーは設けず、本文から表示する。右は問題番号・解答状況・保存状況を一つの設問欄にまとめ、その下に選択肢と解説を並べる。問題文と図表は左側で一度だけ表示し、公式再録・生成問題・復習のいずれでも右側に繰り返さない。狭い画面では同じ構成を縦に並べる。公式再録の原文画像と解答群は問題資料で維持する。

一覧アイコンは表示中の問題資料のページ一覧を開閉する。原文画像のサムネイル又は生成本文の文頭を並べ、ページを押すと左側だけがそのページへ移動する。手ボタンは選択中に背景とアイコンの明暗を反転させてモードを示す。押下状態でドラッグスクロールを切り替え、本文・画像・表・図の縦横スクロールを動かす。リンクと補助テキストの開閉はそのまま操作できる。ズームは左の資料だけに適用し、自動ズーム、実際のサイズ、ページのサイズに合わせる、幅に合わせる、50／75／100／125／150／200／300／400％を選べる。＋／−は近い倍率の段階へ移動する。これらの表示操作は出題内容・解答・時計を変更しない。

解答領域の左端には、全出題の番号を入れた四角いボタンを縦の1列に並べる。解答済みと未解答は背景の濃淡で区別し、現在の番号だけ右端を尖らせて設問を指す。番号を押すと対象の問題へ移動し、問題資料と解答欄を表示する。一時停止中に番号を選ぶと学習を再開し、現在の番号を押した場合も再開する。前後・一覧からの選択でも同じ動作とする。画面の高さと問題数に応じて枠の高さ・文字サイズ・間隔を調整し、すべての番号を折り返しやスクロールなしで表示する。狭い画面でも解答欄の左に1列を維持する。読み上げ用の操作名には未解答／解答済みと見直し状態を含め、現在位置はaria-currentで示す。保存失敗・読込み中は移動を無効にし、復習では保存済みの解答状態を表示する。

```text
上段: OpenCBT FE　科目A／学習　練習名
      [ブックマーク] [一時停止] [正答を見る] [問題一覧]
下段: [一覧] [手] [＋] [−] [自動ズーム ▼]　残り 01:10:20　[終了]
──────────────────────────
共通本文（存在する場合）
問題本文・原文・図表
──────────────────────────
解答領域:
問題 12 / 60　○ 未解答　解答を保存済み
( ) ア　選択肢内容
( ) イ　選択肢内容
( ) ウ　選択肢内容
( ) エ　選択肢内容
[旗] [前へ] [次へ]
──────────────────────────
[IPA公式公開問題（再録）] [改変なし]
```

### ブックマークからの練習

解答・復習画面のヘッダーの補助操作にブックマークボタンを置く。押下状態と「保存済み」で保存状態を示し、再度押すと削除する。時間付き練習でも保存でき、正答を表示する操作とは独立する。年度別とその生成問題は同じ原問題として保存する。

一覧の最上部の操作コンテナには「すべてのブックマークの類題を練習」を右寄せで置く。押すと開始時の全登録問題から毎回ランダムに問題定義を選び、類題を生成する。科目A・Bも同じ練習へ含められる。空一覧では無効にする。メニュー左列の「ブックマーク」から一覧を開き、科目・年度・問番号に加え、元問題の文頭と分野名のラベルを確認して類題を練習する。「問題文の出典・利用条件」を展開すると、各問題の原資料リンクと権利表記を確認できる。一覧が空の場合は解答画面から追加する方法を示す。個別削除は履歴を消さず、履歴の全件削除もブックマークを消さない。

一覧から開いた練習は時間制限なしで一問ずつ生成する。解答・正答表示・一時停止を通常どおり使え、「次の類題」で現在の解答を保持しながら、同じ練習の末尾へ新しい問題を追加する。前の問題へ戻っている場合は保存済みの次問へ移動し、再生成しない。「終了」では全問を集計した結果を表示する。個別練習の「同じ問題で続けて練習」と全件練習の「もう一度練習」は、保存した問題群で新しい練習を開始する。履歴の再開・復習では保存内容を維持し、「次の類題」は復習画面に表示しない。

## S04 — 問題一覧

- 目的：現在位置と解答状況を一覧し移動する。
- 表示：問番号、現在位置、未解答／解答済み、見直しあり、studyの正答表示済み、出自、改変あり／なし、元データ使用／値を生成してバインドの区別。未解答件数・見直し件数。
- 操作：問番号のボタン→対象のS03。未解答だけ／見直しだけの絞込み。「閉じる」→起点のS03。
- 状態：現在位置をaria-currentで示す。解答済みと見直しは両立する。ゼロ件の絞込みは「該当する問題はありません」と示し、元一覧へ戻せる。
- 例外：期限到達は一覧を閉じS06へ。不正参照はS10。正答や正誤をpracticeの一覧へ出さない。

## S05 — 終了確認

- 目的：未解答・見直しを把握して終了を確定する。
- 表示：未解答数、見直し数、終了後は解答変更不可、studyの正答確認数、practiceの残り時間。
- 操作：「問題へ戻る」→S03。「終了して結果を見る」→completed保存・結果生成後S06。初期フォーカスは「問題へ戻る」としEnterの誤操作で終了しない。
- 状態：未解答があっても明示確定で終了できる。保存中は二重送信を抑止する。pausedのstudyからも終了可能。
- 例外：確認中の時間切れはexpiredへ。保存失敗はcompletedと表示せずS10。

## S06 — 結果

- 目的：本アプリ固有の学習結果を確認する。
- 表示：終了理由・日時、科目・mode・セット・当時の改訂、全問数、正解／不正解／未解答、学習正答率、小数第1位、正答確認数、公式IRT評価点・合否と異なる説明、問題別の状態・出自・出典・改変あり／なし・生成枠の区別。
- 操作：「復習」→S07（全問／不正解／未解答／見直しの絞込み）。「新しく選ぶ」→S01。「記録」→S08。出典詳細→S09。
- 状態：completedは「終了」、expiredは「時間切れ」。invalidatedの既存結果は「訂正等により無効」と理由を表示し、確定した現行結果として扱わない。abandonedは指標を出さず記録だけにする。
- 例外：snapshotが失われた場合、学習率の記録値を説明付きで示すことはできるが、問題や正答を現行版で補わない。復習を無効にしS10の詳細を開ける。

## S07 — 復習

- 目的：当時の問題・解答・正答・解説を照合する。
- 表示：当時の選択肢順・解答・正答IDから生成したラベル・正誤、共通本文・問題・独自解説、問題と素材の出典、改変あり／なし・概要・詳細。生成枠は当時のinstance.questionと図データを表示する。
- 操作：番号列・前後・一覧の復習移動、絞込み、S09詳細、S06へ戻る。解答変更・時間計測は行わない。
- 状態：対象0問は空の絞込みと戻る操作を示す。改訂済みは「当時の改訂」と訂正通知。権利理由の撤回は本文・素材を再表示しない。
- 例外：snapshotのhash不一致・参照切れはS10。最新版へ差し替えた復習を過去記録として表示しない。

## S08 — 学習記録・保存設定

- 目的：保存内容を把握し、再開・結果・削除を選ぶ。
- 表示：セッション一覧、科目・mode・状態・最終保存・削除予定日、利用端末内だけに保存する説明、記録が消える条件。
- 操作：running／paused→S02再開。completed／expired→S06。「1件削除」「全件削除」は対象数を確認してトランザクションで削除。独立したボタンを使う。
- 状態：未使用時は空一覧。期限切れは起動時又は一覧表示時に削除。削除後は対象session・result・所有instanceと未参照snapshot・assetを削除する。
- 例外：DBが開けない／削除に失敗した場合はS10へ。成功していない削除を完了扱いしない。ブラウザ標準のサイトデータ削除方法も文章で案内する。

## S09 — 出典・改変・権利詳細

- 目的：問題と部品の出自・条件・変更を確認する。
- 表示：原資料名・主体・日時・locator・原資料リンク、原問と派生元改訂、changesの概要と詳細、部品別origin・rights・license・第三者条件・独自解説。
- 操作：通常のHTTPSリンクで外部資料を別タブへ。リンク先をiframeへ埋め込まない。「閉じる」→S03／S06／S07。
- 状態：独自問題は独立作成経緯と作者を示す。改変の有無・比較対象・履歴、生成枠では基準問題・テンプレート・生成器の版とパラメータを示す。正答を含むanswerDetailsはpractice終了後又はstudyで正答確認済みの場合だけ表示する。日付・期の記載がない項目は推定値で補わず、その旨を示す。
- 例外：リンク先の削除は「外部の資料が閲覧できない可能性」を示し、保存した出典文字列は維持。出典自体の参照切れはデータエラーとして扱う。

## S10 — エラー

- 目的：続行できない理由と残った記録を示す。
- 表示：問題／set／catalog、生成枠ではtemplate／instance／モジュールの識別子と版、エラー分類、最後に保存した日時、継続可否、原因を推測しない説明。内部スタックや個人情報は画面へ出さない。
- 操作：S01又はS08へ戻る、保存記録の削除。再試行は保存失敗・一時読込み失敗の場合だけ明示的に行う。invalidatedセッションを再開させない。
- 状態：開始前はsessionをrunningにしない。開始後はinvalidatedと原因を記録できれば保存する。保存自体が不能ならメモリ上で継続不可を示し、保存できたと表示しない。
- 例外：詳細情報の読込みも失敗した場合、一般的な説明と戻る操作を維持する。

## S11 — ライセンス一覧 {#license-screen}

- 目的：本体コード・外部ライブラリ・コンテンツの適用範囲と利用条件を利用者の操作で確認する。
- 表示：画面名「ライセンス」、本体のリリース版、対象別の一覧とページ内目次。各項目には名称、採用版、権利者・著作権表示、ライセンス名、適用範囲、原文全文、公式参照リンクを表示する。KaTeXはCDN利用であることを併記する。[一覧の内容と元ファイル](/licenses)に従う。
- 操作：S01の「ライセンス」又はS02準備失敗時の同名操作で遷移する。「メニューに戻る」→S01。セット・科目・modeの選択内容を維持し、S01のライセンスボタンへフォーカスを戻す。原資料への外部リンクは明示操作で別タブに開く。
- 状態：ライセンスを開いただけではsessionを作成せず、同意チェックや開始許可の判定に使わない。初回起動でも一覧を空にせず、既に採用を決めたKaTeX等を表示する。一覧と全文は同一originに配置したリリースの通知ファイルから表示し、CDNや問題カタログの取得を必要としない。
- 例外：CDNの停止・セット不足・問題カタログのエラーでも閲覧可能にする。通知ファイル自体の欠落は「ライセンス情報を読み込めません」と表示し、同一配布物の通知テキストへのリンク・再試行・メニューへの戻りを残す。空欄や推測した条件を正常な一覧として表示しない。通知の欠落・一覧と採用版の不一致は本体リリースの検証で拒否する。

問題・図表の必要な出典と改変表示はS03・S06・S07・S09に維持する。S11への集約によって問題単位・素材単位の表示を省略しない。

## キーボード・フォーカス・読みやすさ

Tab／Shift+Tabで全リンク・ボタン・選択肢へ移動する。ラジオグループは矢印キーで選択、Spaceで確定し、グループは1つのTab停止点にする。ボタンはEnter／Space。ダイアログはEscで取消（時間切れ状態は戻さない）、フォーカスを内部へ保持し、閉じると起点へ返す。単一文字のグローバルショートカットは初期版で設けない。

問題移動後は設問見出しへフォーカスし、現在位置と状態を読み上げる。全体スクロールを次問へ持ち越さず本文の先頭へ戻す。目立つフォーカス枠を表示し、ヘッダーがフォーカスを隠さない。

状態は「未解答」「解答済み」「見直しあり」と記号を併用し、色だけを使わない。文字拡大はブラウザ標準を妨げず、200%でも操作できる。幅320pxでもページ全体の横スクロールを発生させず、表・式・コードだけを必要な場合にスクロールする。

残り時間を毎秒live regionで読み上げない。5分・1分・期限到達時だけ文字と穏やかな読み上げで通知する。通常文字のコントラスト4.5:1、操作領域44×44px以上を設計目標として、本体実装後の受入検証で測定する。今回の文書サイトの表示確認を本体のアクセシビリティ試験と呼ばない。
