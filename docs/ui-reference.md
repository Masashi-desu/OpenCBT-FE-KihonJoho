# UI資料の参照方針

## UI-REF-01 — 公開情報に基づく独自仕様化

本システムでは、公開資料から確認した機能・挙動を独立した要件文へ変換し、独自の配置・文言・色・アイコン・操作設計へ反映する。非公開画面の再現、ピクセル単位の複製、本番のHTML・CSS・JavaScript・画像・ロゴ・独自アイコンの利用を行わない。

今回は同一エージェントが資料閲覧・仕様作成・実装を行った。担当を分離したクリーンルーム開発を実施したとは称さず、「公開情報に基づく独自仕様化・独自実装方針」と説明する。

## 資料から独自UIへの対応

| 参照資料 | 確認できた機能・挙動 | 本プロジェクトの要件 | 独自UIへの反映 |
| --- | --- | --- | --- |
| R02・R07 IPA FE・要綱 | 科目別の時間・問数・選択式 | `EXAM-01` A/Bを別セッションで扱う | S01の科目選択、S02の時間・数の説明、S03の残り時間 |
| R08 FE運営FAQ | 基本的にマウスで選択肢を選ぶ | `UI-01` 単一選択と変更を提供する | S03のラジオグループ。キーボードも本アプリ独自に提供 |
| R08 FE案内 | 開始前の操作説明がある | `UI-02` 開始前に説明を読める | S02で操作・保存・本番との差を示す。開始前は本アプリの時間を消費しない |
| R09 受験者規約 | 通常退室では時間を停止しない。機器障害時の特別対応は別 | `SESSION-01` practiceの通常中断で期限を延長しない | S03で閉じても期限継続。studyのみ明示一時停止を提供 |
| R10 汎用体験版案内 | 通常／分割表示の説明、試験ごとに仕様が異なるという限定 | `UI-03` 長文と設問の関係を保って表示する（本プロジェクトの選択） | S03はデスクトップで左に問題資料、右に解答、上下に状態・操作を置く。狭い幅では縦並び。FEの分割表示を保証しない |
| R21 汎用画面の公開画像 | 上の時間・終了、左の資料、右の解答、下の移動操作という配置 | `UI-05` 資料と解答を独立して読める領域にする | 領域の関係を独自React/CSSで実装。画像・配色・文字・ロゴ・アイコンを転用しない |
| R01・R04 公表問題利用案内 | 出典と部分改変の明記 | `ATTR-01` 問題の出自・出典・改変を維持する | 問題見出し直下の帯とS09詳細。結果・復習にも表示 |
| 本プロジェクトの学習要件 | 資料からFEへの適用を確認できない見直し一覧・解除・終了確認・復習 | `UI-04` 学習で迷わず状態を確認するために独自採用 | S03〜S07。公式画面の操作と同じだと表示しない |

引用元・節・適用範囲は[参照資料](/references)で追跡する。共通の機能を採用したことから、その具体的な画面表現や契約条件も利用できるとは扱わない。

## UI-REF-02 — 第三者資料を使う場合

第三者による公開の操作解説を一律に排除しない。採用前に、発行者、URL、日付、対象試験・年度・運営者、情報の由来（公式公開資料・許可されたデモ等）、素材の利用条件、非公開本番情報に依存しないことを調査台帳へ記録する。

機能の説明を抽出する場合も、具体的な文言・図・画面画像・資産をコピーする行為を別に評価する。受験経験から非公開本番を細部まで再現したと説明する資料は、本プロジェクトの画面仕様の根拠へ採用しない。由来を確認できない説明は、第三者を経由したことを理由に使用可能と扱わない。

今回、第三者の本番再現サービスからの機能抽出や資産収録は行っていない。プロメトリックの汎用案内は適用範囲の限定を確認するために参照し、現在のFE本番仕様の保証として用いない。

## 独自UIの視覚方針

背景は淡色、主色は青緑、状態には文字と形を併用する。書体は端末の日本語システムフォントとし、公式のブランド書体や独自アイコンを再現しない。デスクトップの解答画面は資料・解答の二つの領域を持つ。画面幅が狭い場合は縦並びとし、画像・表・コード・図だけをそれぞれスクロール領域にする。アイコンはLucideとし、原文のライセンス通知を同梱する。操作ボタンは意味の分かる日本語ラベルを使う。

独自UIのワイヤーフレームは[画面仕様](/screens)に静的な文字図として示す。これは仕様説明であり、操作可能なCBTプロトタイプとして埋め込まない。
