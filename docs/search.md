# 問題と詳細解説の検索

## 導線と対象

メインメニューは「模擬試験」「検索」「ブックマーク」「履歴・復習」「ライセンス表記」の順とする。従前の「学習をはじめる」は「模擬試験」に改称し、選べる学習モードや出題・保存の動作は維持する。

検索画面は収録された公開問題と、利用できる詳細解説を対象とする。activeかつincludedの問題を使い、テンプレートのbaseQuestionRefに当たるバインド前の定義は公開問題の重複として除く。現在は公開問題103問、詳細解説1件。同じ専用ディレクトリ・改訂を複数の問題が参照していても詳細解説は1件にまとめ、対応する公開問題へリンクする。将来の登録問題・解説も同じ条件で追加され、件数を固定上限にしない。

問題の検索対象はタイトル、年度、科目、分野、学習テーマ・検索語、実際に参照する資料の見出し・本文、問題本文、全選択肢、通常解説、図の代替テキスト、用語の補足とする。参照していないcontextの文章や未生成の入力の組合せ、保存された練習・回答履歴は索引に入れない。画像は既存の文字情報・altから検索し、閲覧時に新しくOCRを行わない。

## 詳細解説の検索用データ

manifest.jsonに任意のsearchを置く。すべて文字データで、検索のためにHTML・JSを実行しない。

| 項目 | 内容 |
| --- | --- |
| search.summary | 検索結果に出す概要。1〜240文字 |
| search.keywords | 学習内容の名称・検索語。最大40件、1件1〜80文字、重複なし |
| search.text | 動的な表示も含む解説の学習内容。1〜10,000文字。コードや保存済み解答は含めない |

searchを省略した従来のパッケージも使え、タイトルと対応問題の学習テーマ・用語から検索できる。searchがある場合は3項目をすべて必要とする。manifestの64KiB上限と、専用ディレクトリ・改訂・全ファイルのhash・素材条件の検査は維持する。検索語が一致しても、資源が欠落・破損・利用不可のパッケージは結果に出さない。

ソート解説ではscripts/update-sort-manifest.mjsが管理下のlesson.jsの独自解説とindex.htmlの静的な文章から検索語・本文を生成する。HTMLのhead・script・style・タグを除き、比較表・計算量の数値例・入力説明も含める。実行するのは作成時の管理下のlesson.jsのみで、検索画面が任意パッケージのJSを評価することはない。対話操作によって切り替わる7方式の説明も索引に入り、「安定」「ピボット」「最大ヒープ」などから探せる。

詳細パッケージの検査は検索画面で行い、最大4ディレクトリを並行処理する。確認中でも問題の結果を表示する。索引はメモリー内だけに持ち、画面を離れると未完の取得を中止する。検索・閲覧によって問題JSON・保存済み出題・回答・結果・ブックマークを更新しない。

## 検索と表示

キーワードは最大200文字。NFKC正規化によって全角・半角を揃え、英字の大小を区別しない。半角・全角スペース等で分けたすべての語が一致する内容を表示する。語は正規表現やコードとして解釈しない。タイトル・学習用語の一致を優先し、その後に年度・科目・問番号で順序を揃える。

「すべて／問題／詳細解説」、科目A／B、公開年度を組み合わせて絞り込める。キーワードを入力して検索又はEnterで適用する。絞り込みの変更時にも入力中のキーワードを適用し、先頭ページへ戻す。「条件をクリア」で全条件を解除する。結果は20件ずつ表示し、該当件数・表示範囲・前後ページを示す。0件では条件を変える案内を出す。

結果には種類、問題名又は解説タイトル、実際の文章の抜粋、学習テーマ、出典・権利を表示する。詳細解説の素材出典は資料名のリンクで示し、定義や計算量を照合した参考資料は詳細画面の専用欄に表示する。検索語をHTMLとして挿入せず、リンク・抜粋はReactの文字表示を使う。

背景・パネル・操作は共通のモノクロのテーマを使う。キーボードで検索・選択・ページ送りを行える。狭い画面ではメニューの5操作を別の行へ置き、各44px以上を保持する。表示領域を変えない[共通の前面スクロールバー](/screens#共通のスクロール表示)を使う。

## 閲覧と状態遷移

| 経路 | 表示 |
| --- | --- |
| #/search | 検索結果 |
| #/search/question/問題ID | 問題の閲覧 |
| #/search/detail/問題ID | 対応する詳細解説の閲覧 |

queryのq、subject、year、type、pageにキーワード・絞り込み・ページを保持する。URLに問題本文・正答・生成値を詰め込まない。結果・問題・詳細の遷移を履歴へ加え、条件変更・ページ送りは同じ履歴項目を更新する。再読み込みとブラウザの戻るでも経路と検索条件を復元する。不正IDや利用不能な問題は検索結果へ戻る案内を出す。

問題の閲覧は資料・本文と、原文画像内の選択肢を表示する。画像の下に独立した選択肢欄を重ねて表示しない。本文下の「問題の操作」に「正答・解説を表示」「詳細解説を見る」「類題を解く」をまとめる。解説関連のボタンは左寄せ、類題は右寄せとし、狭い画面で折り返した場合も類題を右側に置く。詳細解説のボタンは参照先を取得・検査できた場合だけ表示し、正答を表示する前から利用できる。正答・通常解説・用語の補足は最初のボタンで開閉する。

出典・ライセンス・改変情報はこの閲覧画面では常時展開し、素材ごとの適用範囲・追加出典・改変概要・詳細への操作をページ内に表示する。閉じる操作やフッター内の高さ制限を設けない。練習・復習画面の折りたたみは従前どおりとする。

「類題を解く」は閲覧中の公開問題の参照と科目を、既存の1問から始める類題練習処理へ渡す。条件を変えた問題を生成して練習・保存・解答画面へ進み、「次の類題」で同じ系列を続けられる。ブックマークの登録を前提にせず、開始時に登録を追加しない。保存形式は既存のselection.kind=bookmarkとbookmarkQuestionRefを使い、履歴では従来のブックマーク練習と同じ区分へ入る。閲覧・正答表示・詳細解説への移動だけでは練習を作成しない。

画像・数式の取得に失敗した場合は閲覧画面で再試行できる。閲覧用画像のエラーによって別の練習を無効にしない。出典・改変詳細とライセンス全文は同じ閲覧画面のダイアログで開閉する。URL・検索条件・正答の開閉状態・スクロール位置を保持し、閉じた後は起点のボタンへフォーカスを戻す。詳細解説の表示と再生位置もライセンス表示で作り直さない。

詳細解説は[共通の隔離ホスト](/detailed-explanations)で開く。渡すのは公開問題のコピー、元の選択肢順とラベル、問題側の初期指定、themeであり、selectedChoiceIdとgenerationはnull。保存sessionや生成器を使って閲覧用の問題を作らない。通常解説から開いた場合は戻ると表示状態・スクロールと起点のフォーカスを保つ。検索結果から直接開いた場合も通常解説へ戻れる。

詳細解説が取得・実行不能なら、同じ問題の通常解説を表示する。詳細ボタンを除き、同じパッケージの検索結果も現在の検索画面から除く。問題・正答・閲覧済みの通常解説を失わない。通常の練習・保存された生成値からの詳細解説の経路は従前どおり維持する。

## 検証

tests/search.test.tsで、年度別セットに登録した公開問題との一対一、元データ不変、参照資料・選択肢・通常解説・用語の検索、正規化・AND・条件の積集合、詳細の重複除去・完全性・欠落・権利・中止、旧manifestと検索メタデータの検査、URLと閲覧contextを確認する。

node scripts/verify-search-browser.mjsで、隔離したPlaywright CLI用のoutput/playwright/search/verify.jsを生成する。実パッケージによる検索・絞り込み・ページ送り・問題／詳細／戻る・再読み込み、ライト／ダーク、1252／390／320px、キーボード、任意詳細の404、保存領域の件数不変を確認する。操作結果とビルドの記録は[検証記録](/verification)に記す。

同じコマンドが生成するverify-question.jsは、常時展開した出典・操作ボタン・独立した選択肢欄の非表示・正答表示前の詳細遷移・復帰フォーカスを確認する。後半では類題の生成、解答、同一練習への追加、保存済み内容からの再開を検査するため、空の隔離プロファイルでだけ実行する。ユーザーの通常ブラウザや保存済み練習で実行しない。
