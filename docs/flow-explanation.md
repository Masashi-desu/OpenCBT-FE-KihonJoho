# 問11の流れ図・分岐と文字式の追跡

2023年度科目A問11に、HTML・CSS・JavaScriptの詳細解説を追加する。public/explanations/ipa-2023-a-11/を共通の隔離ホストで開き、正答表示・復習・検索から閲覧する。原問題の本文・画像・選択肢・正答を保持し、通常解説に指定経路から3a＝2bを導く過程を記す。

## 図と条件

開始・①・②・⑥・終了を左列、③を②の右、④を③の下、⑤を④の右へ配置する。開始・終了は端子、①④⑤は長方形、②③はひし形、⑥は平行四辺形。処理番号は外側に置く。②から③は水平、③から⑤は右から下へ折れ、④⑤は下側で合流して右端を上がり、①と②の間へ戻る。

初期設定はa＝6、b＝9、②でm＝nなら⑥、それ以外は③、③でm＜nなら⑤、それ以外は④。値は解説用の例で原問の固定入力ではない。代入表記はm←a、n←bを維持する。比較対象と接続先を固定し、＝・≠・＜・≦・＞・≧を定義済みの判定関数へ対応付ける。

分岐を比較結果「小さい・等しい・大きい」の集合で表す。②の条件と補集合、③の条件と②で残った集合の積からラベルと到達不能表示を求める。初期設定では②は＝／≠、③は＜／＞。到達不能の線は破線と文字で示す。③のドロップダウンは指定した演算子を表示し、②の判定でさらに絞られる場合だけ、その隣へ「＞のみ」「到達不能」などの結果を補足する。

## 状態・操作・停止

読み込み・有効な設定変更・最初からは①実行後へ戻る。次へで実際の値から番号付き処理を1つ実行し、戻るで直前のsnapshotを復元する。snapshotは現在位置・次の接続先・mとn・aとbの係数・比較値と成否・通過経路・印字結果・終了／停止理由を含む。履歴先頭で戻る、終了／停止時に次へを無効にする。履歴番号でも同じ状態を復元でき、戻った後の次へは保持した次のsnapshotへ進む。

a・bは1〜9,007,199,254,740,991の整数。空入力、小数、0以下、指数表記、精度超過を拒否し、不正な設定では最後の有効な設定と履歴を保持する。不正な初期値の入力中に演算子を変更した場合も反映せず、ドロップダウンを最後の有効な演算子へ戻す。入力エラーを解消すると、その時点の有効な設定を直ちに反映する。途中結果は負数や0も表示する。数値と文字式の係数をBigIntで減算し、安全な整数の範囲にあるときだけ代入する。精度超過は代入前の値で停止。同じ処理番号・m・nの再出現で循環停止、①を含む512段階で上限停止する。停止後も戻る・最初から・設定変更を使える。文字式は同類項をまとめ、係数1・0を省き、正の項を先にしてb−a、2a−bなどと表示する。

## 表示・解説

主図は全幅を使い、920×570の座標系を幅に合わせる。最小幅760pxより狭い画面では図だけ横スクロールし、分岐の位置関係と約15px以上の文字を維持する。この寸法は他の解説の固定値へ流用しない。図の上の一行には公開問題の選択肢を試すドロップダウンと初期値a・bを置き、入力幅を6chにする。比較演算子は②から⑥、③から⑤へ向かう図中の分岐ラベルを直接ドロップダウンで編集する。図と同じキャンバスへ重ね、横スクロール・表示幅に追従させる。操作対象は44px以上を維持し、図形・配線と重ねない。設定適用ボタンは設けず、選択肢の切替、初期値のinput、比較演算子のchangeで有効な変更を直ちに反映して①へ戻す。編集中のフォーカス・キャレットは保持する。同じ値や同値な表記への変更では履歴をリセットしない。IME変換中は待ち、変換確定時に検証する。整数の範囲と履歴初期化の案内は読み上げ説明へ保持する。

実行履歴は図の右上に配置し、履歴番号と現在位置を一行の横スクロールで表示する。現在の履歴番号は常にその表示域へ収める。図の横幅は狭めず、760px未満では上端の88pxを履歴用に確保して図形との重なりを避ける。凡例は図の右下に小さくまとめる。図から読める比較条件を繰り返す「適用中」の要約と、別置きの履歴説明は表示しない。実際に比較した値・成立判定・接続先、数値と文字式、基準問題の導出は保持する。

主要操作は図の直後、可変の状態説明・入力エラー・図形選択・補足はその後に置き、自然な高さで伸長する。設定行や履歴が変わっても図と主要操作を動かさず、共通色・テーマ・前面スクロールバーと内容高追従を使い、本文から出典・フッターまで一つのページスクロールにする。

図形をクリック・Enter・Spaceで選択し、再選択・閉じる・Escapeで解除して元図形へフォーカスを戻す。実行位置と説明の選択位置を分け、選択では変数・履歴を変えない。現在位置は太枠・▶・処理番号・状態欄、経路は太線で識別する。

現在の解説は適用中の比較条件と履歴から生成する。基準問題の式は標準の比較条件と指定9段階を前提とする。正の整数a＝2k、b＝3kでその経路が成立する。条件変更後はこの結論を現在の結果として表示しない。基準問題の全導出は適用条件を明示した補足で参照できる。

公開問題のア：a＝2b、イ：2a＝b、ウ：2a＝3b、エ：3a＝2bを選ぶと、それぞれ(a,b)＝(6,3)／(3,6)／(9,6)／(6,9)の解説用の例へ切り替える。比較条件は保持し、正の整数の直接入力も引き続き使える。直接入力の比が選択肢に一致すると選択表示も連動し、それ以外は「任意の値」とする。

②又は⑥では、その履歴のm・nの文字式から終了条件を組み立て、移項・最大公約数による約分で関係式を表示する。係数差と約分はBigIntで計算し、負号で両辺を反転するときは大小演算子も反転する。ウの例は④でm＝a−b、続く⑤でn＝b−(a−b)＝2b−aとなり、最後の条件a−b＝2b−aから2a＝3bを導く。実行順は①②③④②③⑤②⑥で3を印字する。標準条件では各パターンの終了経路と原問題の指定経路を区別し、終了するだけで原問題の正解とはしない。比較条件の変更後はその条件に合う式を示し、公開問題の標準条件とは区別する。
