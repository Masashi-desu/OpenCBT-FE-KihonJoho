# PCMの標本化と転送速度

2016年度春期 基本情報技術者試験 旧制度・午前 問4（原資料p.5）の詳細解説。D/A変換解説の図と式の対応、2進数変換解説の段階操作を参考に、共通の詳細解説ホストで表示する。

## 学習の焦点と操作

主図のカードの最上部に、音声の標本化・圧縮なしの転送条件と、何マイクロ秒間隔かを調べる文章を表示する。文中のビット数・転送速度は条件欄および式と同じ値・色で示す。「サンプリング間隔」は時間軸の括弧・式の Δt と色を揃える。類題では保存されたビット数と転送速度を文にも使い、候補の比較中は出題条件を表示する。

連続した音声波形のどこを読むか、読んだ振幅をどうビット列にするか、そのビット列が1秒間にいくつ送られるかを順にたどる。全幅の波形で、時間軸上の等間隔な縦線、波形との交点、最初の2点間の長さ Δt を対応付ける。標本点は直接選べる。選んだ点を図と式に同じ番号で示し、標本化では時刻と振幅、量子化では段階番号、符号化ではビット列を表示する。「戻る」「次へ」と位置スライダーで7段階を往復できる。

音声は独自に作った例示波形とし、先頭の3標本を示す。振幅は0〜1に正規化し、1標本のビット数を b とし、等間隔の2のb乗段階から最も近い段階を選ぶ一例を用いる。原問には波形、量子化規則、符号の割り当てが与えられていないので、これらを使うのはPCMの手順を示す段階までとする。計算は1標本のビット数と圧縮なしの転送速度だけで行う。64,000ビット／秒を8ビット／標本で割ると8,000標本／秒。逆数の0.000125秒を1,000,000倍して125マイクロ秒、原問のウと一致する。

標本点の近くに振幅の近似値を置き、同じ値を代入式に入れる。振幅を示す横の破線、標本点の枠、式の下線で対応を示す。符号化では同じ位置に十進の段階番号を置く。標本数の式では転送速度とビット数の色を条件欄に合わせ、標本間隔の式では秒・マイクロ秒の値を時間軸の括弧に表示する。候補を選んだときは式の候補値の下線、選択したボタンの枠、波形の破線を同じ色で示す。

最後に全4択を試せる。同じ時間範囲の波形へ、候補の標本時刻を破線で重ねる。その候補での転送速度を、標本間隔の逆数と1標本のビット数から求めて問題の条件と比較する。候補値を誤答した理由は仮定しない。表示上の概算と正誤の判定は分ける。

図と主要操作の位置は、ステップ移動・標本選択・候補の比較を通じて維持する。波形の高さは幅に応じて140〜210pxとし、時間軸と間隔の表示領域を確保する。狭い画面の文字拡大時は、スライダーを前後ボタンの下に置き、標本点と重なる中間目盛りを省く。時間軸の括弧では計算済みの値と単位を優先する。現在の説明と比較は操作の後ろで伸びる。同じ点・候補の再選択またはEscapeで解除し、操作元にフォーカスを戻す。段階を移動すると候補比較を解除する。標本化・量子化・符号化の間は標本の選択を保持し、標本数や間隔の計算に進むと各段階の式を表示する。
