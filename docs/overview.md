# 目的・範囲・機能

## 目的と利用者

本システムでは、FEの受験学習者、公開問題を使って復習する人、コンピュータ上で選択・移動・見直し・終了の操作を練習する人を対象とする。学習内容の理解と操作への慣れを支援し、本番環境の外観、非公開問題、IRT評価、公式成績を再現するサービスとは表現しない。

全画面の名称付近に「非公式のFE学習・操作練習」と表示する。プロジェクト名は `OpenCBT-FE-KihonJoho` とし、試験名は対象の説明と問題出典の表示に使用する。公式ロゴや運営事業者の商標画像は使用しない。

## 初期版の範囲

| 項目 | 本システムの仕様 |
| --- | --- |
| 対象試験 | FEのみ。科目A・科目Bを別々に開始・終了する |
| 科目A | 四肢択一。学習分野はtechnology／management／strategy。情報セキュリティはタグでも分類 |
| 科目B | 2〜10選択肢の単一選択。algorithm／security。長文・表・疑似言語を表示 |
| 形式練習 `practice` | 本番問数ではA60問・90分、B20問・100分・16／4。公開部分と独自セットは別の練習区分とし、A1問90秒、B1問300秒。必要数を満たす場合だけ開始 |
| 学習 `study` | セット全問、A1〜60問・B1〜20問、時間制限なし。必要なら正答・解説を見る |
| 復習 | 終了したセッションの当時の問題・解答・独自解説を読む。新規セッションとは別画面 |
| 問題 | 公式再録・公式に基づく改変・独自を明示。部品単位で出典・権利条件を持つ |
| 図・生成 | 管理されたHTML/CSS/JSで配列・フローチャート・グラフを描画。登録テンプレートのパラメータから全出題内容を一体で生成・固定保存 |
| 改変情報 | 出自と別に改変の有無・比較基準・履歴を保持し、出題・結果・復習で表示 |
| 数式 | 制限付きLaTeXを固定版KaTeXで組版する。CDN取得を使用し、オンライン利用を基本とする |
| ライセンス | 最初のメニューに専用ボタンを置き、操作後にライセンス一覧へ遷移。著作権表示・原文全文・適用範囲を示す |
| 保存 | 同一端末・同一originのIndexedDBに保存。認証・クラウド同期なし |
| 結果 | 正解数・不正解数・未解答数・学習正答率・解説表示数を示す |
| アクセシビリティ | キーボード、フォーカス、文字拡大、非色依存の状態表示を備える |

[科目ごとの時間・数の根拠R02／R07](/references)、[モードと公式との差](/sessions)を参照する。文書用の最小サンプルを本体へ流用しない。本体の60問／20問の確保条件と公開部分との差は[実装範囲](/implementation)に従う。

## 含めない機能

本システムの初期版には、認証、課金、SNS共有、自動通知、他試験への汎用設定画面、監督、本人確認、不正対策、合格予測、公式IRT算出、科目A免除・科目間休憩を含む通し受験、答案アップロードを含めない。

問題の自動収集・PDF自動変換・大量取り込み、未登録の生成器・利用者コード・外部AIによる問題生成、疑似言語の実行、電卓、メモ帳、ヒントは含めない。登録テンプレートによる生成は[図描画・問題生成](/diagram-generation)に限定する。問題原文への外部リンクは出典確認用であり、外部データを自動取得しない。

## 今回の成果物と配信範囲

資料確認後の明示的な指示に基づき、srcの本体、配布カタログ、検証、静的ビルド、GitHub Pagesワークフローを作成した。2026年10月7日の公開指示に基づき、mainへのpushで[本体アプリ](https://masashi-desu.github.io/OpenCBT-FE-KihonJoho/)を自動配信する。文書の閲覧環境はnpm run doc、本体の開発環境はnpm run devで起動する。[構成](/architecture)と[起動方法](/contributing)に従う。

## 用語

| 用語 | 定義 |
| --- | --- |
| 問題 `question` | 1つの設問と単一の正答を持つ不変の改訂単位 |
| 共通本文 `context` | 問題内で設問が参照する長文・表・図等。1問の中で関連付ける |
| 出典 `source` | どの資料のどこから取得・確認したかを示す情報 |
| 権利レコード `rights` | 利用根拠、対象部品、用途別判断、表示条件を保持する情報 |
| 改変 | 原問題の特定表現に依存した内容変更。単に「類題」と呼んでも同じ扱い |
| カタログ `catalog` | 配布するファイルの許可リストと各ファイルのハッシュ |
| セッション `session` | 開始時の出題順、選択肢順、利用者の解答・見直し・時刻・状態 |
| 学習結果 `result` | 当時のセッションに基づく本アプリ固有の学習指標 |
