# 本文・図表・疑似言語

## 採用形式

本システムでは、本文・選択肢・解説に**型で判別する構造化ブロック**を採用する。問題データに任意HTML、スクリプト、Vue、Markdownを格納してレンダリングする機能は持たせない。段落・見出し・表セル等の文章はプレーンテキストとしてDOMへエスケープして表示する。数式ブロックだけは以下の限定した記法で組版する。

`common.schema.json` の `content` は `attribution` と順序付き `blocks` から成る。問題文は `prompt`、共通本文は `contexts[].content`、選択肢は `choices[].content`、解説は `explanation` に同じ型を使う。部品の出典・権利はcontentごとに付け、画像はさらにasset単位で付ける。

問い方だけでなく、全問題の前提・注意書きを原資料と照合する。「ここで」「ただし」「なお」、図表の注記、疑似言語のコメントに含まれる記号・集合表記、入力域、配列添字、未定義要素、単位、端数処理、繰返しを実行しない条件を保持する。例えばX→Yの意味とX→{Y，Z}の意味は両方を本文に示す。バインドによって添字やビット幅などを変える場合は、その定義も同時に更新する。解答に必要な条件はprompt又はcontextRefsで参照する本文・図表に表示し、explanationや読み上げ専用の図のaltだけに移さない。

## 許可するブロック

生成時は原問題の文章・箇条書き・表・図・空欄付き疑似言語の区分を保持する。条件が文章で示されている問題へ補助表を追加しない。元の図が文章を枠で囲ったものの場合は、contexts[].presentation=text_figureで枠と図のcaptionを保持する。省略時は通常の参照本文となる。3.0.0の初回公開前の仕様補足としてこの任意フィールドを定義し、従来の省略されたデータも受理する。[生成契約](/diagram-generation#原問題の出題形式の維持)を参照する。

| type | 必須の内容 | レンダリング規則 |
| --- | --- | --- |
| `paragraph` | `text` | 段落として表示。日本語を折り返す。改行を保持。HTMLとして解釈しない |
| `heading` | `level` 2〜4、`text` | 問題内の見出し。画面全体のh1と混在させず順序を保つ |
| `list` | `ordered`、`items[]` | 1階層のul／ol。項目のテキストにHTMLを含めてもタグとして実行しない |
| `table` | `caption`、`columns[]`、`rows[][]` | captionと列thを持つ矩形table。全行同じ列数。長いセルは折り返し、表全体は必要な場合だけ横スクロール |
| `image` | `assetId`、`caption` | asset IDを解決し、asset.altをimgの代替テキストへ。直下にキャプションと素材の権利表示 |
| `diagram` | `id`、`rendererRef`、`caption`、`alt`、`attribution`、`scene` | 登録済み描画器にJSONの配列・ノード・辺を渡し、固定のHTML/CSS/JSで描画する。代替説明を読み上げ用に保持し、原図の凡例と素材別条件を表示 |
| `formula` | `text`、`alt`、任意の`format` | `format=latex`はKaTeXで数式だけを組版する。`unicode`又は省略は文字式として表示。数値の計算は行わない |
| `code` | `language`、`text` | pre/codeで改行・インデントを保持。空白を潰さない。表示用言語種別のみで実行処理を呼ばない |

簡単な文字式には `× ÷ ≤ ≥ ≠ ← ∑ x²` 等のUnicode文字も使用できる。分数・指数・添字・平方根・対数・総和・行列・場合分けの組版には、以下のLaTeX形式を使用する。結合セル、音声・動画、任意リンク、iframe、埋め込みHTML、クリック可能な回答欄を本文ブロックへ追加しない。

diagramの描画コードは開発側の本体コードで管理し、問題データへHTML/CSS/JSを格納しない。許可するscene、モジュールの版、表示・安全性・生成時の整合は[図描画・問題生成](/diagram-generation)に従う。

## 数式のデータと組版

本システムでは数式部分の描画にKaTeXを採用する。`formula.format`は`unicode`又は`latex`で、省略時だけ`unicode`として扱う。`text`と`alt`は各1〜1000文字の必須文字列であり、`null`・空文字は拒否する。`latex`のtextはASCIIの数式記法と空白だけを受理し、日本語の説明はalt又は隣接するparagraphに置く。[数式Schema](/schemas/formula.schema.json)と[正本サンプル](/samples#数式の説明用例)を参照する。

数式は独立したブロックとして本文・選択肢・解説の任意位置へ置き、表示モードは全て独立行とする。段落・表セル・箇条書きの文字列に書いた`$...$`等は自動変換しない。本文全体のauto-render拡張は導入しない。式が長い場合は式の領域だけを横スクロールし、altを「数式の説明」として直後に常時表示する。KaTeXのHTMLとMathMLを併用し、画面幅や拡大のために数式を切り落とさない。

許可する制御命令の正本はformula Schemaの`$defs.allowedLatexCommand.enum`とする。分数、指数・添字、平方根、対数・三角関数、総和・積、比較・論理・集合記号、床・天井記号、基本の文字スタイル・間隔を扱う。環境は`matrix`、`pmatrix`、`bmatrix`、`cases`、`aligned`に限定し、最大8行・各行8セル、環境の入れ子なし、波括弧の深さ16以下とする。二重バックスラッシュによる改行はこれらの環境内だけで使用できる。

`$`による区切り、コメント、マクロ定義、利用者指定のマクロ、リンク、画像、HTML、CSS、任意寸法指定、ファイル参照・入出力を拒否する。未知命令を赤字の文字列へ置き換えて正常扱いにしない。描画設定は`trust:false`、`throwOnError:true`、`strict:"error"`、`output:"htmlAndMathml"`、`displayMode:true`、`maxExpand:100`、`maxSize:10`とし、毎回空のmacrosを渡して数式間で状態を共有しない。データから設定やCDN URLを上書きできない。[公式設定資料](https://katex.org/docs/options.html)の機能をこの制限内で使用する。

数式表示は正答計算と分離する。生成器が確定した値からtext・alt・正答・解説を一体で作り、生成済みquestionへ保存する。KaTeXには表示用textだけを渡し、式を評価して正答を得る処理、利用者の解答の送信、疑似言語の実行を追加しない。内容hashにはformat・text・altも含める。

## KaTeXのCDN取得と失敗時の動作

本システムではオンライン利用を基本とし、KaTeX **0.19.0**をjsDelivrから読み込む。オフライン専用配布、Service Workerによる保存、ローカルのKaTeX代替配布を初期版へ追加しない。ブラウザの通常キャッシュが残っていても、オフライン利用可能とは表示しない。実際に確認した導入資料・条件・限界は[R16〜R18](/references#数式ライブラリとcdn)に記録する。

固定する取得先は次の2ファイルである。CSSが参照するフォントは同じ版の`dist/fonts/`から取得する。`latest`、版の省略、別CDNへの自動切替を使わない。以下のSRIは確認日に実ファイルのSHA-384と照合した。

| 資産 | 固定URL |
| --- | --- |
| JavaScript | [katex.min.js](https://cdn.jsdelivr.net/npm/katex@0.19.0/dist/katex.min.js) |
| CSS | [katex.min.css](https://cdn.jsdelivr.net/npm/katex@0.19.0/dist/katex.min.css) |

```text
JavaScript integrity:
sha384-QFFtAGzvvj+bfgCGxXJlNZZR1nXEZgvG8tDLCCY1F19xl20WlfTYgguB4VcNdxYk
CSS integrity:
sha384-3rdsX6e5mueWyoweR9NIVmtEsUkokpBT/0ALqKKIBMr9j4qhHkaIkAcGgsE6uVlp
```

取得要素に`crossorigin="anonymous"`を設定し、Referrer-Policyは`no-referrer`とする。SRIは上記JavaScript・CSSの取得を検証するもので、CSSから取得する全フォントの個別SRIやサービスの継続性まで保証するものではない。CDNへの通信とライセンス一覧への案内をS01・S02へ表示する。

S01メニュー、S08記録一覧、S11ライセンス一覧はKaTeXの読込みに依存させない。S02では選んだ全問題・生成結果の本文・選択肢・解説にlatexがある場合だけ依存資産を取得し、各式の組版と必要フォントを事前確認する。1回の準備は10秒で打ち切る。準備完了前はrunningにせず、タイマーを開始しない。latexがないセットはCDNを取得せず開始できる。

通信・SRI・必要フォントの読込み失敗は「数式表示の準備に失敗しました」と表示して開始を止め、「再試行」「選び直す」「ライセンス」を残す。別版や説明文だけでの出題へ自動変更しない。不正な式はデータエラーとしてS10へ移る。開始後に組版不能が判明した場合も進行を止め、保存可能ならinvalidatedとしてS10へ移る。再開説明中も既存practiceの期限は進む。復習時の一時的なCDN障害では結果を無効化せず、式のaltと「組版を表示できません」を示して再試行できるようにする。

本体には数式描画・準備を実装する。文書サイトにはCDNスクリプトを組み込まず、読み取り専用の仕様・JSONを表示する。

## 長文と設問

科目B相当の長文は `contexts[]` へ格納し、`contextRefs` で設問との対応を示す。表示順は参照順の共通本文、その後にprompt、その後にchoicesとする。選択肢を操作しても共通本文の内容は変化しない。

共通本文と設問の見出しに名前を付け、キーボードやスクリーンリーダーで移動できるようにする。本システムはデスクトップで資料を左、解答を右へ分け、狭い幅では縦並びにする。上下・左右の配置が変わってもcontextRefsとの関係を保持する。

## 安全性とサイズ

本体のカタログは1MiB以下、個別JSONは2MiB以下、画像は静止PNG／JPEG／WebPで2MiB以下・4096×4096px以内とする。最大の文字数・行数・列数・ブロック数はSchemaに記録する。過剰サイズ、未知フィールド、未知type、外部画像URL、`..`を含むパス、SVGを拒否する。

URLを持てるのはsource等の明示フィールドだけで、HTTPSとし、認証情報付きURLを拒否する。本文のURLに見える文字列を自動リンク化しない。出典リンクは明示的なユーザー操作で開き、`noopener noreferrer` を付ける。データ中の疑似言語・SQL・スクリプト風の文字列をeval、Web Worker、サーバ実行へ渡さない。

アセットはカタログに含まれる同一配布物内の相対パスだけを解決する。取り込み時は再エンコード・メタデータ除去・完全デコードで静止画像を確認し、MIME、寸法、hashを固定する。文書サンプルの検証はPNG寸法、本体配布検証はWebP署名・サイズ・hashを確認し、開始・再開時のブラウザでは完全デコードと寸法を確認するが、あらゆる画像形式のデコーダ安全性を保証しない。

## 文書サイトとの違い

文書サイトは仕様書とJSONサンプルを表示する閲覧環境であり、CBTの出題・解答・採点は行わない。[サンプル](/samples)は元JSONを読み取り専用のコードブロックとして示す。

## 原形式を保つ表・登録図

遷移確率の表の左上セルなど、列見出しが存在しない位置はcolumnsの空文字で明示する。これは省略と区別し、他の列・行との対応を保持する。入力と出力の斜め区切りは列見出し「入力＼出力」又は「出力＼入力」だけを固定CSSで描き、読み上げには行軸・列軸を文字で示す。任意HTML・任意CSSは許可しない。元表で数値を示さないセルは文字列「非表示」を使い、網掛けと読み上げ用の「非表示」に対応させる。表の行列数を変える補助説明は加えない。

source_figureは図の固定プロファイルに整数値列を渡す。登録15形状・位置別入力域は[生成対応一覧](/generation-coverage#登録図の入力契約)に示す。添字・配列の網掛け・回路の反転小円・波形・斜め接続・凡例を図の中で表現し、代替説明はSVGのtitle／descへ保持する。SQLコードは「SQL · 表示のみ」、疑似言語は「疑似言語 · 表示のみ」と表示し、両方とも実行しない。
