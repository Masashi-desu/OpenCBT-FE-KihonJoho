# アローダイアグラム・操作で学ぶクリティカルパス

## 初期条件と原問題の照合

2024年度科目A問13・2025年度科目A問14の通常解説・検索・復習から開く、HTML/CSS/JavaScriptの問題専用コンポーネント。配置はpublic/explanations/ipa-2024-a-13/、共通の[詳細解説ホスト](/detailed-explanations)で隔離実行する。問13の初期値は収録済み原問題と同じA=30、B=5、C=30、D=20、E=40、F=25、G=30、H=30日。上側→中央、中央→下側のダミーは0日で、両方を有効にする。

元問題の最短完了は120日（ウ）。最早時刻は開始0、分岐30、上側35、中央60、下側60、合流90、終了120日。クリティカルパスはA→C→ダミー（中央→下側）→G→H。ダミーを省いた作業名だけの表記ではA→C→G→Hとなる。

原冊子・公式解答・公開問題の利用条件を2026-10-14に再確認した。[問題冊子の6ページ](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/eid2eo0000007g1d-att/2024r06_fe_kamoku_a_qs.pdf#page=6)、[解答例](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/eid2eo0000007g1d-att/2024r06_fe_kamoku_a_ans.pdf)と収録画像を照合している。図の接続構成はIPA原図に基づく改変としてmanifestに記録し、rights-ipa-2024-aとrights-originalを分けて継承する。操作UI・計算説明・コードは独自作成。原問題の本文、全選択肢、正答は保持する。

## 問14のパターンと学習の焦点

表示切替チェックボックスと同じ操作欄の左端に置く「図のパターン」で2024年度科目A問13と2025年度科目A問14を切り替える。問14から開いたときは問14を選び、生成問題ではその保存済み条件を使う。図の上下・接続・折れ線を原図と対応させ、問13と同じ1000×470の表示領域に作業A〜Iと2本のダミーを描く。切替で編集日数・ダミー・計算位置・選択・拡大率・横スクロールをパターン別に保持し、自動再生を停止する。「初期値に戻す」は選択中のパターンだけを、原値又は保存済み条件へ戻す。

問14では、段階的な合流で「すべての到達を待つ」ことを比べる。原値はA=3、B=6、C=8、D=6、E=5、F=14、G=11、H=15、I=5日。E完了点→B終点、G完了点→C終点が0日のダミー。B・Eの合流は9日、C・F・Gの合流は20日、D・Hの合流は26日、終了は31日（エ）。クリティカルパスはA→B→G→ダミー→D→Iとなる。問14は8地点と3回の到達比較、最後の経路確認の12段階で追跡し、選んだ地点の式と矢印の強調を対応させる。数値入力は複数桁・空欄などの編集中状態を計算へ混ぜないため、従来どおり一つの作業を「適用」又はEnterで確定する。パターン・表示切替・ダミーは選択時に即時反映する。

原冊子p.8の図と全選択肢27・28・29・31、公式解答のエを2026-10-16に再照合した。[2025年度問題冊子](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/tbl5kb0000005r9r-att/2025r07_fe_kamoku_a_qs.pdf#page=8)を公式から取得し、登録済みSHA-256と一致した。[公式解答例](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/tbl5kb0000005r9r-att/2025r07_fe_kamoku_a_ans.pdf)、[公開問題の使用条件](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/index.html)、[FAQ](https://www.ipa.go.jp/shiken/faq.html)にも到達し、出典・改変表示を継承した。図の構成にはrights-ipa-2025-a、追加した操作・説明にはrights-originalを適用する。第三者帰属の表示は特定しなかったが、権利不存在を保証するものではない。

| 問14の条件 | 最短完了 | 注目する変化 |
| --- | --- | --- |
| 元の問題 | 31日 | G経由の到達20日がDの開始を決める |
| E=7日 | 32日 | Eの完了を待つダミーがB終点を10日にする |
| F=25日 | 39日 | Fの到達28日がDの開始を決める |
| H=17日 | 31日 | DとHの到達が26日で一致し、2経路になる |
| H=18日 | 32日 | H経由が完了日を決める |
| G側ダミー無効 | 29日 | Hの到達24日がIの開始を決める |

ダミーを無効にしてE又はGに後続がなくなっても、その作業自体の完了は全体の完了条件に含める。終端となった全作業の最大完了時刻を求め、終了地点の式にも表示する。例えばE=100日でE側ダミーを無効にした場合は103日、G=100日でG側ダミーを無効にした場合は109日。後続がない作業を計算から消さない。

## 図上の操作

問題専用のタイトル・最短完了日数・条件説明のヘッダーと、独立した凡例・再生フッターを設けない。表示切替と拡大縮小は図の面へ配置し、「計算をたどる」を図の左下、「初期値に戻す」を右下へ置く。完了時刻は終了地点、選択内容、読み上げ通知で確認する。表示中のパターンの出典・ライセンス・改変情報を単一フッターへ常時展開する。問13は2024年度問13・p.6、問14は2025年度問14・p.8へ切り替え、日数やダミーを編集した場合も原図を基にした改変として表示する。元問題用のフッターと解説の小さな権利行を重ねない。出典・改変詳細ダイアログも現在のパターンに合わせ、戻ると元問題の通常表示を保持する。

単一の図の表示領域で、実線の作業、円の結合点、破線のダミーを選択する。図の下にPCでは最小高さ280px、600px以下では最小320pxの説明領域を初期表示から確保し、見出し・計算式・編集操作・時刻をその領域の幅全体へ直接配置する。独立したカードの枠・影・中央寄せの幅制限・接続用の点線を設けない。PCでは日数入力と時刻を横に並べ、狭い画面では縦に並べる。選択前と閉じた後には操作案内を表示する。説明領域は再生・初期化操作の後へ配置し、長い内容や補足の展開・文字拡大では下へ伸ばす。本文・説明欄の縦スクロールは設けず、共通ホストが内容高へ追従して出典・フッターまで画面全体でスクロールする。図と説明を左右の別ペインへ分離せず、図を横スクロール・拡大できる。スクロールバー・色・フォントは本体の正本を使う。

- 日数の条件プリセットは設けず、図上の選択から編集する。図のパターンだけを同じ操作欄の左端の選択欄で切り替える。作業の矢印・作業名・日数から直接選択し、結合点の計算表示に作業やダミー設定への遷移ボタンを設けない。作業A〜H又はA〜Iは現在値を入れた数値入力から編集する。「適用」又はEnterで確定し、閉じても値を保持する。0以上の整数を受理し、空欄、負数、小数、指数表記、不正文字を拒否する。入力が不正なら計算状態を変えず、入力欄の近くにエラーを表示する。
- 作業の所要日数、最早・最遅の開始と終了、トータルフロート、最早と最遅の時間帯を表示する。各作業が余裕を同時に独立して使えるという説明にはしない。
- 結合点では先行作業の到達時刻と最大値の式を表示する。計算項目を選択すると対応する矢印を強調する。関係のない矢印は薄くする。
- ダミーは0日の依存関係と説明し、各パターンの2本を個別に有効・無効へ変更する。無効な破線は残して状態を示し、計算対象から除く。
- クリティカルパス、最早時刻、ダミーの強調を切り替える。クリティカルパスが複数ならダミーを含む全経路を表示する。図上の経路と作業選択の説明が対応する。
- 最初、前へ、次へ、自動再生、一時停止で問13は9段階、問14は12段階を追う。先行地点を計算してから接続先へ進み、E・F・Gの到達比較と合流の最大値を分け、最後にクリティカルパスを示す。日数や依存関係を変えると再生を停止し、計算過程を再生成する。
- 矢印・円はEnterとSpaceで選択できる。選択中の同じ対象をクリック・タップ又はキーボードで再選択すると解除し、表示領域を操作案内へ戻す。確定した日数とダミーの有効・無効を保持し、再生中なら停止する。編集欄へフォーカスを移し、Escape又は閉じるで選択元へ戻す。入力と主要ボタンは44px以上の高さを確保する。
- 選択、編集、補足の展開、開閉で図の高さや「計算をたどる」の位置を変えない。クリティカルパス一覧は図の下の予約領域へまとめ、ステップの状態表示は図内の再生操作と併記する。

## 計算と保存互換

arrow-engine.jsは有効な矢印だけでトポロジカル順序を作り、最早時刻を前向きの最大値、最遅時刻を後ろ向きの最小値で計算する。余裕時間は最遅終了−最早開始−所要日数。余裕0日の矢印を開始から終了へつなぎ、全クリティカルパスを求める。ダミー無効時に後続がなくなった作業も終了対象とし、全作業の最大完了時刻を使う。整数はBigIntで計算し、浮動小数点の精度不足による丸めを起こさない。長い日数は図のラベルを省略表示し、選択時と読み上げには完全な値を使う。矢印の長さ自体は日数を表さない。

生成問題ではgenerator-critical-path 2.1.0／2.2.0のA〜H、generator-source-2025-a-14 3.2.0／3.3.0のA〜Iを保存済みparameters.valuesから初期条件にする。問題文を解析したり最新の生成器で再生成したりせず、操作用状態だけを変更する。「初期値に戻す」はその保存済み条件と両ダミーを復元する。

パッケージは改訂2。問13の原問題を改訂4、基準問題・テンプレートを改訂10、問14の原問題を改訂3、基準問題・テンプレートを改訂8へ更新する。問題生成の計算と入力域は変更せず、生成器2.2.0／3.3.0を保持する。基準hash、由来・セットの参照、カタログを更新する。非互換な履歴には既存のヘッダー案内と最新版による別の学習を使い、旧回答・正誤・結果を引き継がない。ブックマークは問題IDから現行改訂へ解決する。検索では同じパッケージでも初期表示が異なる原問題を別々に索引し、2025年度の絞込みから問14を開ける。

## 検証方法と範囲

tests/arrow-simulator.test.tsでは原図から別に固定した接続表の全経路を列挙し、最早時刻、最遅時刻、余裕、完了日、全クリティカルパスを照合する。問13は0・1・2日の全6,561入力×ダミー4状態=26,244ケース、問14は全19,683入力×4状態=78,732ケースを検査する。両方の原値、条件変更例、100個の再現可能な追加入力、60桁の整数、無効入力、計算順序、保存済み条件、旧版の再開・追加・復習、パッケージのhash・素材条件を検査する。小さい領域の全列挙と代表的な大きい値の確認であり、任意の全整数の網羅検証とはしない。同一AIによる査読であり、人の二重校正ではない。

ブラウザ用の確認スクリプトは `npx tsx scripts/verify-arrow-browser.ts <起動済みURL>` でoutput/playwright/arrowへ生成する。隔離したPlaywright CLIでverify.jsとgenerated.jsをrun-codeのfilename指定で実行する。指定された1362×1313と1280px、390／320px、両テーマ、表示領域の幅全体を使う配置、下部操作の位置保持、全作業の図からの直接編集、遷移ボタンの不在、説明領域の最小高さと内容への伸縮、本文・説明欄の縦スクロールの不在、無効入力、結合式、ダミー、複数経路、再生、フォーカス、元画面への復帰、生成問題の保存済み値を確認する。generated.jsは専用ブラウザのIndexedDBへだけ検証用記録を保存する。

問14の追加確認は `npx tsx scripts/verify-arrow-patterns-browser.ts <起動済みURL>` でpatterns.jsとgenerated-2025.jsを生成する。隔離ヘッドレスCLIのrun-codeで両方を実行し、原問31日、A〜Iの全編集、段階的な合流、ダミー無効時の全作業完了、複数経路、全12ステップ、切替時の状態保持・再生停止、1280／390／320pxの両テーマ、文字拡大、無効入力、キーボード、単一ページスクロール、保存済み条件・通常解説への復帰を確認する。既存の問13用スクリプトも回帰確認に使う。

資源を変更したら `node scripts/update-arrow-manifest.mjs` で共通色・スクロール実装の複製とmanifestを更新する。完了時には `npm run check` を通す。ローカルでの成功を公開サイトへの配信完了とは扱わない。
