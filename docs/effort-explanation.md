# 開発工数と最少要員

2019年度春期 基本情報技術者試験 旧制度・午前 問54（原資料p.24）の詳細解説をpublic/explanations/ipa-2019-spring-am-54/に配置する。共通ホストを使い、検索・通常解説・復習から開く。D/A変換解説の図と式の相互選択、キャッシュヒット率解説の段階計算と全選択肢比較を参考にする。追加ライブラリは使わない。

## 学習の焦点と操作

本数と1本当たり工数を掛けてから合計し、追加工程の倍率を適用し、開発日数で割って最少整数人数を求める。8段階は「表の読取り／入力処理／出力処理／計算処理／コーディング合計／設計・テストを追加／人数と切上げ／1人少ない場合の検算」とする。戻る・次へ・スライダー・段階選択で往復できる。原問は20＋30＋45＝95人日、追加760人日、総工数855人日、95日で9人、正解イ。95人日と95日の同じ数値の異なる役割、追加の8倍と全体の9倍を区別する。

主図は全幅の一領域に表・集計・内訳の棒・総工数÷日数→人数・現在の式を順にまとめる。A〜Cは処理の行、Dはコーディング合計、Eは設計・テスト、Fは総工数、Gは開発日数、Hは最少人数。同じ記号を図と式のボタンへ付け、選ぶと対応する行・要素を枠で強調し、主要操作より後の説明を数値の出所へ切り替える。再選択・解除・Escapeで選択元へフォーカスを戻す。段階移動は選択を解除する。現在の段階の対象とユーザー選択を別の太さの枠で示し、記号と段階名も併用する。

処理別工数の表には共通の境界色による外枠と、見出し・全セルの縦横の罫線を設け、列と行の対応を保つ。罫線はborder-collapseで一本にまとめ、図内の横スクロール領域には外周の線を欠けさせない1pxの余白を取る。

表の本数・1本当たり工数、図中の追加倍率・開発日数を直接編集する。入力フォーカスでも対応先を強調し、有効な整数を随時反映する。編集時は段階と選択を保持し、同値入力・IME変換中には計算を更新しない。空欄・範囲外・小数などは直前の有効な図と計算を保ち、入力欄とエラーで未反映を示す。初期化は保存済み条件・最初の段階へ戻す。自動再生や重複した適用操作を設けない。

表の各結果・合計・人数は段階に応じて表示し、最後だけ最少人数と1人少ない人数の確保工数を比べる。倍率0、割り切れる場合、余りが出て切り上げる場合、1人で足りる場合も扱う。小数へ丸めず、商と余り及び正確な分数で確認する。全選択肢比較と用語・前提は排他的に開く補足とし、変更条件での比較と保存問題の選択肢を区別する。確保工数が足りても最少でない選択肢を判別する。棒は作業量の割合で、工程の日程や実務の増員効果を表さない。

図の要素を全段階で保持し、現在の式の高さは実際の幅・文字サイズで8段階を測って必要な最大値だけを予約する。600px以下で追加工程を縦に並べ、表だけを図内で横スクロールする。文字拡大時も44px以上の操作対象を保持する。説明・エラー・補足は主要操作より後で自然に伸長し、共通ホストの単一縦スクロールと共通色・前面スクロールバーを使う。親のタイトル・出典を埋込内へ重ねず、単独表示だけ見出しと出典を出す。
