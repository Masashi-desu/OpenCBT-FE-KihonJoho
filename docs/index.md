# OpenCBT-FE-KihonJoho 仕様書

本システムでは、公開情報を根拠にしたFEの学習とCBT形式の操作練習を提供する。非公式の独自UIを使用し、IPA・試験運営事業者の公式サービスであると表示しない。

2026年10月6日の明示的な実装開始指示を受け、仕様書と文書サイトに加えて、静的配信できるCBT学習アプリを実装した。[実装・収録データ・配信](/implementation)で現在の動作と収録範囲を確認できる。全仕様は左の仕様一覧、各節はページの目次から移動する。

## 仕様の読み方

「本システムでは」という記述は本プロジェクトの具体的な要件である。外部の事実は資料ID `R01` 等とURLで追跡する。資料から直接確認できる内容と、プロジェクトで選んだ動作を分ける。外部情報を確認できない点は、推測で公式仕様を補わず、対応するシステムの扱いを記載する。

基準日は2026年10月6日（日本時間）である。外部サイトの更新を継続監視しているわけではない。制度・規約・ライブラリが変更された場合は[保守](/maintenance)に従う。

説明用サンプルのユーザー状態は架空である。公式例は実際の2025年度FE科目A公開問題の問16のみで、その他の問題は改変例又は独自の説明用問題である。文書用サンプルと、本体が読むpublic/dataの配布カタログは分離する。本体には2023〜2026年度の公式公開問題103問と、原画像・記述に基づく生成テンプレート103種類の改変済み基準問題を収録する。ランダムミックスは全問を生成し、独自学習問題という別の出題セットは設けない。
